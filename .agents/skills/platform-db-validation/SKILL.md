name: platform-db-validation
description: 验证盛和塾运营平台数据库结构变化的前向迁移、MySQL 兼容性和安全恢复。用于迁移开发或数据库验证任务；不用于普通页面修改。
---

目标是提供可复核的隔离验证证据。先读 [工程工作流的验证矩阵](../../../docs/engineering-workflow.md#验证矩阵)，仅检查本次相关迁移及调用方。

1. 确认迁移序号、依赖和影响表。核验 MySQL 字段类型、字符集、排序规则及外键兼容性；保留应用层组织范围校验。
2. 使用任务专用的可丢弃本地／CI 数据库和脱敏或合成数据。核验连接目标后执行，不读取生产凭据来构造测试环境。
3. 验证前向迁移、重复执行行为和相关数据不变量。涉及 MySQL 的变化不能只交付 SQLite 测试结果；复用 `.github/workflows/ci.yml` 的相关隔离任务，B2 只用于其专项范围。
4. 在相应迁移边界验证回滚。存在后续外键或已形成业务事实时应拒绝不安全降级；记录备份恢复或前向修复路径，不为了测试通过删除真实数据或绕过保护。
5. 输出迁移集合、隔离目标、执行结果、恢复证据及剩余缺口。此技能不授权执行生产迁移；生产动作另按工程工作流核验明确批准。
