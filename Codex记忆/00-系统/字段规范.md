# 字段规范

项目正式记忆和候选记忆必须包含以下 YAML 字段：

- `memory_id`：小写 kebab-case 唯一标识。
- `type`：decision、preference、workflow、lesson、open-loop、knowledge、summary 或 capture-candidate。
- `status`：inbox、reviewed、needs-review、superseded 或 archived。
- `updated`：包含时区的 ISO 8601 时间。
- `source`：用户确认、任务标识或正式文档。
- `confidence`：high、medium 或 low。
- `sensitivity`：public、internal 或 confidential。
- `project`：本项目使用 `seiwajyuku-platform`。
- `tags`：必须包含 `codex-memory`。

正文先写结论，再写范围、证据、边界与关联记忆。禁止保存密钥、口令、完整对话、隐藏推理和未经确认的个人推断。
