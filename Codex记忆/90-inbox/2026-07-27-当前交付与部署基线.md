# 当前交付与部署基线

平台已从只读可行性预览升级为腾讯云 CloudBase 上的可登录、持久化业务系统；年度 MP 看板和月度填报已由用户确认可用。

## 已确认范围

- 前端基于 `pure-admin/pure-admin-thin` 改造，部署在同一 CloudBase 环境的独立静态目录 `ops-platform/`。
- 后端为独立 CloudRun 服务 `seiwajyuku-platform-api`，使用独立 MySQL、环境变量和敏感字段密钥，不复用签到系统业务表。
- 项目代码和说明已建立私有 GitHub 仓库 `spring-chao/seiwajyuku-platform`，默认分支为 `main`。
- 2026 年 MP 已导入 1 至 6 月完整数据，以及 7 月月 MP 和预定；看板按指标、月份和分中心展示。
- 月度填报按分中心组织，百分比和数值按整数显示；看板增加年度目标达成率。
- 学员管理字段已对齐旧运营管理系统的新增学员信息范围，学员编号由系统生成。
- 手机号加密保存、列表脱敏；年销售额和利润率按敏感信息加密保存。
- 关怀跟进支持创建任务、责任人权限过滤、任务态临时查看联系方式、电话记录、企业走访和关闭闭环。
- 第 8 项活动与签到仍保持外部扫码链路独立，本平台只提供快照、自动指标和管理查询入口。

## 验证证据

- 线上门户、CloudRun 健康接口和静态资源返回 HTTP 200。
- 责任人候选路由已从错误的 404 修复为受鉴权保护的接口。
- 最新隐私与关怀回归测试 8 项通过，前端类型检查与 staging 构建通过。

## 边界

- 不在记忆中保存账号密码、数据库凭据、密钥、完整手机号或完整会话。
- 学员示例模板没有作为正式数据导入；正式批量导入仍需经业务核对。
