# 学长服务助手小程序

这是学长服务助手的微信原生小程序入口，不使用 `web-view`。未绑定身份时提供新学长信息登记；绑定正式学员后，首页收拢为“我的学习 / 我的成长”，志工学长另外看到“志工服务”。扫码能力保留为辅助路由，不再占用首页主入口。提交后继续调用现有平台 API，后台审核、收款确认、正式分中心和正式入册流程不变。

## 当前正式发布配置

- `project.config.json` 使用正式 AppID `wx9622a0ab5070ae2d`，`setting.urlCheck=true`。
- `config.js` 使用正式 API 网关 `/platform`，运行环境标记为 `PRODUCTION`。
- 微信公众平台必须配置该 API 网关的 request 合法域名；正式 AppID 的域名配置不会继承测试 AppID。
- AppSecret 永远不写入此目录、GitHub 或小程序源码，只由后端环境变量管理。

## 发布前配置

1. 确认 `project.config.json` 中的正式微信小程序 AppID 与微信公众平台一致。
2. 在 `config.js` 中确认正式 HTTPS API 网关，并把网关域名加入微信公众平台的“request 合法域名”。
3. 在微信公众平台配置用户隐私保护指引，覆盖姓名、手机号、生日、企业资料、职位和学习意愿等信息的收集用途。
4. 后端配置 `WECHAT_MINIPROGRAM_APP_ID`、`WECHAT_MINIPROGRAM_APP_SECRET` 和 `WECHAT_MINIPROGRAM_PAGE`，后台才能生成正式小程序码。
5. 首次发布后，从运营后台新建或轮换一次入塾入口，再下载小程序码。旧 H5 链接仍可作为备用入口。

## 入口参数

小程序码进入 `pages/enrollment/index`，使用 `scene` 携带当前有效入塾入口令牌。新建/轮换的令牌为短 URL-safe 随机值，适合放入微信小程序码；历史 H5 令牌仍由现有 API 兼容解析。

## 绑定学员后的首页入口

- `我的学习`：展示当前学习周期与最近已接入的本人学习事实；正式学分仍处于建设中，不自行估算。
- `我的成长`：展示脱敏姓名、班级、小组和已接入的志工服务记录；没有数据时显示“暂无记录”。
- `志工服务`：只显示当前身份实际有权限使用的服务，目前复用小组学习会登记入口。

`pages/scan/index` 仍保留，用于兼容已有直达链接和后续具体业务二维码；它不作为首页主入口。

首页入口只是现有能力的体验外壳，不新增身份主键、数据库表或积分结算逻辑。普通正式学员不会看到学习会登记，新学长申请在绑定成功后从首页隐藏。

## 体验边界

- 首屏明确显示“新学长信息登记”、运营服务主体、审核说明和“不进行转账或收费”提示。
- 页面只负责收集申请资料，不在小程序内确认付款、不直接建立正式学员档案。
- 完成提交后显示“资料已提交”“当前尚未正式入册，无需重复提交”。
- H5 页面保留为微信之外或小程序未发布时的备用渠道，不再作为日常印刷二维码的主入口。
