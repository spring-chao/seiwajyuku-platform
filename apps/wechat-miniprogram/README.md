# 学长服务助手小程序

这是盛和塾运营平台的微信原生小程序入口，不使用 `web-view`。未绑定身份时提供新学长信息登记；绑定正式学员后，首页收拢为“我的学习 / 扫码 / 我的盛和塾 / 我的服务”四个入口。提交后继续调用现有平台 API，后台审核、收款确认、正式分中心和正式入册流程不变。

## 当前内部测试配置

- `project.config.json` 当前固定为测试 AppID `wxb63212d3ce337b81`，描述中的 `[TEST]` 是有意保留的环境标记。
- 测试阶段 `setting.urlCheck=false`，只用于微信开发者工具预览和真机调试；不能把这份配置当作正式发布配置。
- 正式小程序下来后，只替换 AppID、配置合法 HTTPS 域名并恢复 `urlCheck=true`；页面和后端业务代码不需要重写。
- AppSecret 永远不写入此目录、GitHub 或小程序源码，只由后端环境变量管理。

## 发布前配置

1. 在 `project.config.json` 中替换正式微信小程序 AppID。
2. 在 `config.js` 中确认正式 HTTPS API 域名，并把该域名加入微信公众平台的“request 合法域名”。
3. 在微信公众平台配置用户隐私保护指引，覆盖姓名、手机号、生日、企业资料、职位和学习意愿等信息的收集用途。
4. 后端配置 `WECHAT_MINIPROGRAM_APP_ID`、`WECHAT_MINIPROGRAM_APP_SECRET` 和 `WECHAT_MINIPROGRAM_PAGE`，后台才能生成正式小程序码。
5. 首次发布后，从运营后台新建或轮换一次入塾入口，再下载小程序码。旧 H5 链接仍可作为备用入口。

## 入口参数

小程序码进入 `pages/enrollment/index`，使用 `scene` 携带当前有效入塾入口令牌。新建/轮换的令牌为短 URL-safe 随机值，适合放入微信小程序码；历史 H5 令牌仍由现有 API 兼容解析。

## 绑定学员后的四个入口

- `我的学习`：展示当前已接入的学习服务；尚未接入历史学习/学分数据时显示“暂无记录”，不自行估算。
- `扫码`：调用微信扫码能力；当前能识别的学习会二维码沿用现有学习会登记流程，其他二维码给出明确提示。
- `我的盛和塾`：展示脱敏姓名、班级、小组和已接入的志工服务记录；没有数据时显示“暂无记录”。
- `我的服务`：只显示当前身份实际有权限使用的服务，目前复用小组学习会登记入口。

四个入口只是现有能力的体验外壳，不新增身份主键、数据库表或积分结算逻辑。普通正式学员不会看到学习会登记，新学长申请在绑定成功后从首页隐藏。

## 体验边界

- 首屏明确显示“新学长信息登记”、运营服务主体、审核说明和“不进行转账或收费”提示。
- 页面只负责收集申请资料，不在小程序内确认付款、不直接建立正式学员档案。
- 完成提交后显示“资料已提交”“当前尚未正式入册，无需重复提交”。
- H5 页面保留为微信之外或小程序未发布时的备用渠道，不再作为日常印刷二维码的主入口。
