# 项目文档说明

本目录保存盛和塾运营平台的正式项目文档，不是 Codex 长期记忆库。

## 内容边界

- `baseline/`：需求与技术设计基线
- `tasks/`：任务卡、实施清单和验收要求
- `verification/`：审核、验证和核对报告
- `deployment/`：部署与运维说明
- [engineering-workflow.md](engineering-workflow.md)：现行授权、验证和完成条件；工程任务按需读取
- [deployment/ordinary-release.md](deployment/ordinary-release.md)：现有服务的普通发布步骤

统一长期记忆库位于：

`E:\盛和塾运营系统\Codex记忆`

需要独立交付文档时保存在本目录，内容与任务影响相称。仅用户明确要求归档时提炼已核验结论到统一记忆库；历史报告与未完成事项不构成新的操作授权。
