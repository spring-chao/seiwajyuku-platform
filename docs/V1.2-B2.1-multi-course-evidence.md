## 页面

- 组长/辅导员：选择成员 → 没有课程/有课程 → 多选实际观看课程 → 拍摄或选择一张合影 → 提交。
- 可选 0、1、3 或更多课程，没有“三门上限”；只展示服务器积分标准，不能填写分值。
- 拍照/相册每次只选一张，压缩后预览，可重新选择；成功页展示全部课程及“合影已上传”。
- 上传或提交失败保留服务端草稿 ID 重试；点击提交期间禁止重复请求。
- 运营后台：学员运营 → 小组学习会记录，或 /operations/study-meetings。
  详情可查看私有合影，获授权人员可修正已提交记录的课程列表，备注选填，不需学长重提。
  清空课程表示未观看。并发修正使用原课程列表校验，拒绝覆盖他人的修改。

## 合影安全与存储

原仓库无可复用合影/COS 上传服务，本次新增 study_evidence_storage 独立适配层：

- dev/test：显式独立本地目录，禁止作为静态目录公开；部署环境禁止回退本地盘。
- COS：服务端 SDK 上传私有对象，服务端鉴权后代理读取；客户端不持有云密钥、对象路径或公开 URL。
  bucket、region、SecretId、SecretKey、可选临时会话 token 均只通过后端环境变量注入。
- 请求体在 multipart 落盘前限流量大小；真实文件最多5MB，解码验证 JPEG/PNG，拒绝损坏、
  超大像素、非图片、多帧文件，重新编码去掉 EXIF/GPS 和附加内容。
- 先保留上传元数据再写对象，上传失败仍可清理；写入和替换/提交使用同一学习会行锁。
- 图片读取每次校验权限、有效任职和组织范围、保留期、大小与 SHA；响应 no-store/nosniff。
- 默认168小时后不可访问。cleanup_study_evidence.py 默认 dry-run，--apply 才删除对象，
  保留学习事实/元数据/审计；失败可重试，重复运行不重复删除。
- 本轮不配置定时任务；清理脚本只允许 dev/test。未来生产启用前必须单独审批私有 COS、
  最小权限凭据、环境隔离、生命周期/清理任务，不能把本地清理测试当作生产保留期已部署。

参考：[腾讯云 Python SDK](https://cloud.tencent.com/document/product/436/12269)、
[Pillow 文档](https://pillow.readthedocs.io/en/stable/reference/Image.html)。
依赖版本固定在 requirements.txt，COS 适配器通过模拟调用验证，不冒充腾讯云实机验收。

## 开关（默认均不扩大生产权限）

```text
STUDY_MEETING_EVIDENCE_ENABLED=false
STUDY_MEETING_COURSE_EDIT_ENABLED=false
STUDY_EVIDENCE_RETENTION_HOURS=168
STUDY_EVIDENCE_STORAGE_BACKEND=local  # 仅 dev/test
STUDY_EVIDENCE_LOCAL_ROOT=<独立绝对路径>
```

即使上传开关关闭，也不能绕过“有一张有效合影才允许首次提交”。
历史 SUBMITTED 记录保持原状态；照片到期不会撤回已提交事实。
COURSE_EDIT 与 STUDY_MEETING_REVIEW_ENABLED 是独立开关。
LEARNING_CREDIT_SETTLEMENT_ENABLED 继续 false。
