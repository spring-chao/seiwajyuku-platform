## 修复

1. 首页根据已验证身份与服务器有效 assignments 分别判断：
   未绑定显示绑定/新申请；已绑定且有权限显示登记；普通正式学员不显示两个业务入口。
2. 成功绑定显示“欢迎回来 / 学习服务从这里开始”；不再向已绑定学员请求公开申请链接。
3. 仅 me=401 清除本地失效会话；网络/500不能把已绑定用户误判为申请人；context失败不解除身份。
4. 解绑定后清除岗位信息；异步旧响应不能覆盖解除后的新状态。
5. 后台错误明确区分401登录、403权限、404版本/开关、500后端/迁移、网络失败；保留接口路径。
   不输出原始 Axios 请求配置/令牌或服务端traceback。
6. 本地登录页不再固定写“生产环境已启用”；登录页与记录页明确标出本地验收和API地址。
