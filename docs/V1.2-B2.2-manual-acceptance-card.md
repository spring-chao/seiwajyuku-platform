# V1.2-B2.2 人工验收卡

日期：2026-08-28。**本轮为只读预审，不需要业务人员登录或再次操作。**

当前未创建腾讯云合影测试环境、测试资源或测试账号，也未批准真实 COS 写入。这张卡定义下一阶段的交付要求，**不是已经可执行的云验收邀请**。不得把已有本地图片测试称为腾讯云图片验证。

| 必填项目 | 当前状态 / 交付方式 |

| API网址 | 同上，须与管理端、小程序同一测试环境；明确不是生产 API |
| 管理端登录账号 | 测试账号待核验；可复用独立本地种子的 `admin`，不可默认与生产同名账号混用 |
| 登录密码/获取方式 | 不存文档、Git或普通对话；实施人员通过本机受控凭据入口提供或现场填入，经业务人员确认可登录后再交卡 |
| 微信测试 AppID | 沿用现有 TEST 配置，不切正式 AppID；验收前核对配置及本地API目标 |

任一项未准备好，不要求业务人员寻找密码、猜手机号或自行修环境。种子脚本只用于隔离库；不让业务人员到生产创建假学员。

## 业务人员实际操作

1. 打开已实测的小程序测试入口，用提供的合成组长身份绑定，看到本人和负责小组。
2. 登记测试学习会，选择本组学员，可加一位同班跨组学员、选两门课程，上传一张标记为内部测试的图片。
3. 提交，预期成功页明确记录已保存，不显示积分已发放。
4. 登录同一测试环境管理端，打开“小组学习会记录”，看到名单、课程及合影；刷新后仍可查看。
5. 根据测试图片修正参加人员/课程，预期保存成功，合影不变、正式班组不变、修改有审计。
6. 由实施人员切换到已到期的合成记录，业务人员刷新：预期提示照片已到期，不再显示图片，但学习会、名单、课程和修正历史仍在。

## 实施人员完成，不转嫁给业务人员

- 未登录、越组织、无权限访问应拒绝；COS源站及任何CDN地址不能匿名取得测试图片。
- 超5MiB、伪造MIME、损坏/多帧图片拒绝；已接收图片不含原EXIF/GPS。
- 模拟上传失败、激活DB失败和替换失败，页面不能假成功，旧合影不丢。
- 到期后核实 COS 对象已删除、`storage_deleted_at` 与 audit 正确；第二次清理幂等；删除失败重试和告警有效。
- 验证运行临时凭证刷新及实际网络路径；如采用长期凭证，核对独立最小权限和轮换流程。
- 冻结测试ID、日志摘要、测试对象范围及清理结果，不保留人脸、密钥或手机号在报告中。

## 禁止操作

不连接/迁移生产数据库；不绑定真实学员；不上传真实合影；不修改正式组织关系；不发积分；不发布正式小程序；不改生产开关；不清空桶或删除其他业务对象；不把测试账号提供给无关人员。

本卡在下一阶段填齐实际环境与凭据获取方式并验证后，才标记 `READY FOR HUMAN ACCEPTANCE`。当前：`NOT REQUESTED / AWAITING APPROVED TEST SETUP`。
