## 1. 范围与不变项

本轮把现有 CloudBase 标准版环境的内置私有云存储接入 `study_evidence_storage`，不创建新 COS Bucket，不新增 migration，不购买资源，不部署 CloudRun，不修改生产 Feature Flag，不写真实学习会或学员照片。

`2026` 学习计划、V1.2 学习事实、课程积分结算、微信身份写入均不在本轮范围内。

## 2. 适配器实现

- 新增 `STUDY_EVIDENCE_STORAGE_BACKEND=cloudbase`，仍保留旧 `local`/`cos` 兼容路径。
- CloudBase 桶、地域和前缀均由环境变量注入，不在源码写死桶名：

  ```text
  CLOUDBASE_STORAGE_BUCKET=<StorageInfo.bucket>
  CLOUDBASE_STORAGE_REGION=<StorageInfo.region>
  CLOUDBASE_STORAGE_PREFIX=study-meetings/
  ```

- CloudBase 前缀强制为 `study-meetings/`；对象键为：

  ```text
  study-meetings/<environment>/YYYY/MM/<random-uuid>.jpg|png
  ```

  不包含姓名、手机号、member_code、班级或小组名称。
- 上传保持私有 ACL，并使用 `If-None-Match: *` 防止同名覆盖。
- 读取仍由 platform-api 在既有身份、岗位和组织范围校验后代理，不返回永久公开 URL，不经过 CDN。
- SDK 凭证优先读取运行时注入的 `TENCENTCLOUD_SECRETID/SECRETKEY/SESSIONTOKEN`，以 `CredentialInstance` 方式按请求读取；仅在运行时凭证不存在时兼容受控的 `CLOUDBASE_STORAGE_SECRET_*` / 旧 `STUDY_EVIDENCE_COS_*` 环境变量。凭证不进入 Git、前端、日志或 `.env.example`。

## 3. 过期与清理

- `expires_at` 仍是业务真相，默认 `STUDY_EVIDENCE_RETENTION_HOURS=168`。API 在到期后立即拒绝读取，与物理删除是否完成无关。
- 新增显式配置：

  ```text
  STUDY_EVIDENCE_CLEANUP_ENABLED=false
  STUDY_EVIDENCE_CLEANUP_GRACE_SECONDS=900
  STUDY_EVIDENCE_CLEANUP_PREFIX=study-meetings/
  ```

- staging/production 只有在清理开关显式开启、后端为 `cloudbase`、前缀精确为 `study-meetings/` 时才允许清理；`--apply` 仍受 `DEPLOYMENT_READ_ONLY` / `ALLOW_PRODUCTION_MUTATIONS` 写入门禁保护。
- production/staging 只扫描 `expires_at` 已经过安全 grace 的记录；dev/test 保留旧的废弃预留清理兼容行为。
- 每批最多500条；逐对象锁定、再次核验过期状态、校验 namespace/key 前缀后删除。对象不存在视为成功，删除完成才写 `storage_deleted_at` 和审计；单条异常不会中止整批，重复执行幂等。
- 清理脚本不会读取或删除 `study_meeting_evidence` 之外的表，也不会改变学习会、参加人员、组织关系或积分。

## 4. 上传替换与故障补偿

上传顺序保持：预留 metadata → 上传新对象 → 锁定草稿并激活新 metadata → 写审计 → 后续清理旧对象。上传/激活失败会标记预留记录为逻辑删除，并尽力删除本次尝试的对象；补偿删除失败时保留可重试 metadata。不会先删旧照片，因此新照片失败不会使旧照片丢失。

清理在 COS 删除成功但数据库提交失败时会在下一次运行重试；COS 的对象不存在响应按幂等成功处理。

3. 当前 `STUDY_MEETING_EVIDENCE_ENABLED`、`WECHAT_MEMBER_BINDING_ENABLED`、`STUDY_MEETING_SUBMISSION_ENABLED`、`STUDY_MEETING_REVIEW_ENABLED`、`LEARNING_CREDIT_SETTLEMENT_ENABLED` 均保持关闭，B2.4 代码完成不等于生产合影已上线。

> **CloudBase 内置存储复用和应用适配代码已完成；生产接入需要先确定运行身份与零新增费用清理调度，随后再另行批准配置变更和合成对象云端烟测。**
