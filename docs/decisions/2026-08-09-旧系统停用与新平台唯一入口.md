# 旧系统停用与新平台唯一入口决策

日期：2026-08-09

## 决策

从本决策起，`seiwajyuku-platform` 是盛和塾运营工作的唯一日常平台。旧 `seiwajyuku_system` 不再继续建设、不再录入新数据，也不再作为人员、组织、签到、续费、MP 或身份权限的业务来源。

旧系统仅在退役完成前承担两项受限用途：

1. 只读盘点历史数据；
2. 在隐私、安全和数量核验通过后，提取统一平台尚未承接且确有保留价值的历史事实。

## 数据边界

- 学员主档和正式组织关系以统一平台为准；旧系统中的姓名、手机号和名称文本关系不得反向覆盖；
- 签到名单以统一平台 `member_org_relations` 为唯一来源，签到记录继续由现有签到同步链路进入统一平台；
- 旧系统中的签到同步表属于历史缓存，不作为二次迁移来源，避免重复签到；
- 旧账号、角色、权限和公开排名逻辑不迁移；
- 无稳定学员编号的数据不得通过姓名或手机号猜测匹配；
- 现场扫码、二维码和签到写入链路不因旧系统退役而改变。

## 退役顺序

1. 完成旧库表级数量盘点和隐私安全导出；
2. 对确需保留的数据生成只读预检报告；
3. 核验统一平台已承接的数据口径和数量；
4. 留存可恢复的数据库备份及代码版本；
5. 关闭旧系统公开入口，数据库转为只读归档；
6. 在统一平台运维文档中记录恢复责任人与恢复步骤。

关闭公开入口不等于删除旧数据库。任何删除必须在备份可恢复、数量核验完成后另行执行。
