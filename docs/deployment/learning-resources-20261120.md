# 学习资源中心接入

从“我的学习”进入学习资源中心，首页副标题固定为“提高心性、拓展经营”。学习资料沿用已核对的原图、链接和36个月课程顺序。

第三年第十一个月、第三年第十二个月均不配置学习视频二维码。图片53（原表L27）内9个码属于其他班级运营和志愿者培训，只在独立运营资料中显示。原表位置作为来源追溯，不能推导为学习月份。其他34个月映射不变。

新增只读接口 `/api/v1/wechat/learning-resources`：有效学员可读取课程目录和月份资料；`committee=true` 重新校验当前有效的八类班组委岗位，待人工核对或无对应岗位时返回403。客户端不携带运营资料静态副本，不新增数据库、岗位或下载审批。学习资料浏览不写入学分或签到。

二维码采用原资料的内嵌图像，客户端落地原始字节后提供放大、保存、复制链接。微信原生页通过保存图片识别或复制链接访问外部资源，不引入未经配置的网页域名。

发布顺序：目标提交CI通过后，经现有发布控制器上线API，再上传同提交的小程序版本，按微信审核和正式发布流程完成。API回退使用发布前核验的稳定版本，小程序使用原正式版本；无需数据库回滚。未完成的微信审核不能记为上线成功。
