# 微信原生小程序入塾登记 V1.1

更新时间：2026-08-25

## 目标

将“新学长扫码登记”的日常入口从普通 H5 URL 二维码升级为微信原生小程序码，避免新学长在微信内打开外部网页时遇到额外的非官方网页确认层。H5 页面保留为微信之外或小程序未发布时的备用入口，不使用 `web-view` 套壳。

## 业务边界

小程序只负责展示登记说明、收集申请资料和提交公开入塾申请；后端仍按原规则写入 `member_enrollment_applications`，不直接创建正式学员档案。后台审核、确认分中心、确认收款和正式转入 `members` 的流程保持不变。

## 入口设计

- 页面：`pages/enrollment/index`。
- 小程序码 `scene` 携带当前有效短入口令牌；新建/轮换令牌使用 128 bit URL-safe 随机值，长度不超过微信小程序码限制。
- 后端仍只保存入口令牌摘要；原始令牌只在创建/轮换后的当前管理浏览器会话中暂存。
- 后台主按钮下载微信小程序码，同时保留 H5 备用链接和备用二维码。

## 页面口径

- 第一屏使用中性服务型名称“学长服务助手”和“新学长信息登记”，明确运营服务主体、资料用途、审核说明和“不进行转账或收费”。
- 表单字段按《最新修订后盛和塾苏州分中心学员加入申请书(2026)》设计，包含手机号、企业资料、学习意愿和三项入塾原因等字段。
- 提交完成后明确显示“资料已提交”和“当前尚未正式入册，无需重复提交”。
- 手机号和企业资料继续由后端加密保存；小程序不调用微信用户身份、头像或手机号授权接口。

## 上线前置条件

- 替换正式 AppID，并在微信公众平台配置 request 合法域名。
- 后端安全注入 `WECHAT_MINIPROGRAM_APP_ID`、`WECHAT_MINIPROGRAM_APP_SECRET` 和 `WECHAT_MINIPROGRAM_PAGE`。
- 配置并审核用户隐私保护指引，覆盖本表单实际收集的信息和用途。
- 发布小程序后重新创建或轮换一次入口并下载小程序码；生产状态和配置必须在发布前实时核验。
