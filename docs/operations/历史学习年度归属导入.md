# 已有余额的历史学习年度归属

适用于已经入账累计余额、补录最近已完成学年年度统计的班级。此次黄埔一班使用用户指定的第二学年原表，用户确认原表末月“8月”实际是2026年9月，第二学年12次学习日已完成。统计截止日与原期初余额保持2026-09-30。原文件和表头不改写，更正口径进入来源说明和审计。

## 操作

学分结算工作台新增“补充历史学习年度”。选择班级、原表所属学年、统计截止日，填写年度及月份确认说明，上传年度原表。系统检查姓名在本班有效名册中唯一匹配、原公式与缓存一致、年度分值不超过未归属的累计余额、截止日与原余额一致。检查结果显示原行号、匹配编号、分值及需要处理的问题。任何一行不通过都不能提交，不模糊匹配、不静默跳过学长。

提交来源后，学习条线的现有 `plans:credit_opening_manage` 权限人员复核和确认归属，可由同一人员完成。确认后只写入年度归属及班级历史学习进度，不修改原余额、不向正式活动账本加分。原学年保留；历史24次学习日之后进入第三学年0分，之后只累计截止日以后的真实学习日和正式学分。没有提供的第一学年显示待补充，余额未归属的部分继续显示待补充，不伪造0分。

普通活动结算继续保留独立审批；年度归属沿用期初余额管理授权，不增加权限或取消业务门禁。小程序仍只读当前绑定学长的数据，整数显示沿用向零截断，存储保留小数。
