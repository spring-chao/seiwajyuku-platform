# 小程序学习年度学分展示

2026-10-10 用户确认：每年度 12 次学习日，完成后进入下一学年；新学年从 0 分累计，上一学年记录保留。学分显示直接去掉小数，账本保留原始精度。

- 我的学习主数字显示当前学习年度已明确归属的学分，下方分别列第一、第二、第三年度；超过三年度时继续列出对应年度。
- 年度进度由当前班级学习计划下已确认 `HELD`、具有实际时间且不在未来的学习日计数。计划月份推进、周期编号、自然年和个人出席次数均不代替实际学习日计数。
- 第 12 次学习日本身及其周期的学分属于第一年度，第 13 次属于第二年度；第 24 次属于第二年度。完成第 12／24 次后，当前主数字切换到下一年度，原年度记录保留。查询只读，不清零或改写旧账本。
- 正式账本记录依其已记录学习周期归入对应年度；晚入账仍保留来源周期的年度。冲销与原记录归于同一年度，仅使用当前学长的原记录，不读取其他学长的分值。
- 未记录可核验周期的历史分、期初累计余额单独标示待补充年度归属，不擅自分摊至三个年度。没有配置当前学习服务时显示“学习年度待配置”，不假定第一年度。
- 首页学分卡、全部学分记录及详情统一向零截断显示。例如 `12.99` 显示 `12分`，`-2.99` 显示 `-2分`，`-0.99` 显示 `0分`。先按原值汇总，再截断汇总显示；不将展示整数写回数据库。

API 的原累计和自然年字段继续保留以兼容旧客户端。新增 `current_learning_year`、`current_learning_year_points`、`current_learning_year_completed_days`、`learning_days_per_year`、`learning_years` 及未归属提示字段，由当前绑定学长身份解析；不接受查询参数选择他人的学分。
