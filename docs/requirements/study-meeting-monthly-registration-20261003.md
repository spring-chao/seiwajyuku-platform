# 小组学习会仅登记与班级按月更新

2026-10-03 用户明确要求：学习完成情况只作登记，允许没有完成课程继续下一步；已绑定学习计划的班级每月自动更新，无需逐班手动操作。此要求取代“只能在确认班会后推进学习内容”的旧规则。

小程序第一页和提交页均允许选择“尚未完成”或暂不选择后继续。实际选项保留在本次页面状态中，不把未完成改成完成，不生成课程积分。实际参加人员、身份授权、当前内容配置和合影校验继续执行。

后端通过 `LEARNING_CYCLE_MONTHLY_REFRESH_ENABLED=true` 启用月度模式。保留只读环境和生产写入门禁；本任务不修改 IAM、学分门禁、数据库结构或计划绑定。启动时及运行中每小时扫描有效绑定，获取班级进度或小程序登记上下文时也会补齐，适应容器空闲或停机。月界限为上海时区每月一日零时，按班级锁与事务串行推进，同月重复请求和多个实例不会重复推进。

更新以现有开放周期所在月为起点；当前绑定曾人工校正时，以该次校正所在月与周期开放月中的较晚者为起点。因此本月校正为第六次的班级本月保持第六次，下月进入第七次。新学习轮次的正式开始时间未到之前不推进。明确延期到未来的周期保留延期，计划内容缺失或存在重复有效绑定时拒绝更新该班，其余班级继续。

自动更新仅关闭旧内容期间、打开下期内容，保存审计与原始时间；不补造实际班会、课程完成、缺席、小组任务或学分。月度模式下“确认班会”只确认本期真实班会，不再次推进内容。真实班会确认后当前内容仍保持到月末，重复确认被拒绝，次月自动切换。历史统计只有具有实际班会事实的周期计入“班会已完成”；纯日历结束显示“期间已结束”。达到计划最后一期后停止自动增加，不自动毕业或重新开始，后续计划仍由运营确认。

未绑定的班级无法推断其学习计划、模板与起始周期，保持“未绑定”待维护；不会自动套用其他班级配置。现有历史登记及其学习周期、课程快照、学分规则版本保持原记录。

部署时使用经过 main CI 验证的同一提交，并仅增加上述月度功能配置。生产 API 使用现行受控发布脚本继承稳定版本网络；网络基线不完整时停止该部署。小程序预览、代码完成与生产月度功能已生效分别记录，不相互替代。
