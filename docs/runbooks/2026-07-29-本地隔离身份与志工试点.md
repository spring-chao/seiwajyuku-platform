# 本地隔离身份与志工试点

更新时间：2026-07-29

## 用途

在不连接生产数据库、不修改真实账号和权限的前提下，为网页验收准备四种合成账号：

- 运营中心专职人员；
- 担当志工；
- 同行志工；
- 技术管理员。

种子数据包含一个试点分中心、班级、小组、一名合成学长和一项待回应的服务邀请。所有名称均明确标注“隔离试点”，不对应真实个人或企业。

## 安全门禁

`scripts/seed_local_identity_pilot.py` 仅在以下条件全部满足时运行：

1. `APP_ENV` 为 `dev`、`test` 或 `staging`；
2. 数据库为 SQLite，且文件名包含 `pilot`；
3. `ALLOW_PRODUCTION_MUTATIONS=false`；
4. 身份授权、身份写入和服务邀请三个试点开关显式开启；
5. 管理员和四个试点账号密码均从环境变量传入且至少 12 位。

脚本不会输出密码，不会连接远程数据库。

## 环境变量

```text
APP_ENV=dev
DATABASE_URL=sqlite:///./data/local_identity_pilot.db
ALLOW_PRODUCTION_MUTATIONS=false
IDENTITY_AUTHORIZATION_ENABLED=true
IDENTITY_ADMIN_WRITES_ENABLED=true
VOLUNTEER_SERVICE_INVITATIONS_ENABLED=true
BOOTSTRAP_ADMIN_USERNAME=pilot-admin
BOOTSTRAP_ADMIN_PASSWORD=<local-only>
PILOT_OPS_PASSWORD=<local-only>
PILOT_VOLUNTEER_PASSWORD=<local-only>
PILOT_COMPANION_PASSWORD=<local-only>
PILOT_TECHNICAL_PASSWORD=<local-only>
```

## 启动与回滚

初始化后启动 API 和管理端，管理端的本地 API 地址指向隔离 API 端口。

回滚时停止本地 API 与管理端，然后删除 `data/local_identity_pilot.db`。该文件被 `.gitignore` 排除，删除它不会影响开发库、staging 或生产数据库。

## 网页验收顺序

1. 专职账号确认服务事项和邀请寄语；
2. 担当志工确认温暖语言，可接受、建议调整时间或说明暂时无法参与；
3. 接受担当后邀请同行志工；
4. 同行志工确认可以共同记录，但不能查看完整联系方式或结束事项；
5. 技术管理员确认不能访问学长与服务事项业务数据。
