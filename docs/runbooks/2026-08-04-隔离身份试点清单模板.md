# 隔离身份试点清单模板

本模板只用于隔离环境试点准备，不填写密码、完整手机号或未经确认的自然人推断。

## 试点范围

- 运营中心专职：1 个账号，岗位从已确认的八类运营中心岗位中选择
- 三级分中心：1 个分中心，仅作为服务责任范围验证
- 班级：1 个班级，仅作为组织范围验证
- 志工：少量账号，至少覆盖 1 个班级/小组服务范围

## 逐项确认字段

| 字段 | 填写要求 |
|---|---|
| 隔离账号标识 | 使用测试账号或内部短标识，不填密码 |
| 身份类别 | 运营中心专职 / 学长志工 / 技术管理员 |
| 业务确认依据 | 任命文件、审批单、会议决议或确认编号 |
| 业务确认说明 | 说明身份事实、岗位/任职和有效期限 |
| 任职组织 | 组织 ID 和组织名称 |
| 服务责任范围 | `UNIT` 或 `SUBTREE`；明确“不是组织归属” |
| 开始时间 | ISO 8601 时间 |
| 结束时间 | 必须明确；技术和志工任期不能无限期 |
| 回滚责任人 | 试点结束、撤销或异常时的业务负责人 |

## 通过条件

1. 账号只能看到其有效岗位或志工任职允许的数据范围。
2. 技术管理员不能访问学员、企业敏感资料、联系方式或敏感导出。
3. 志工任职到期、停用或撤销后，相关权限立即退出授权上下文。
4. 每次关联、任职和状态变更均有审计记录。
5. 试点完成后可以按事务快照回滚，不影响旧 IAM、学员关系、签到事实或扫码链路。

## 当前门禁

- 生产身份写入开关保持关闭。
- 真实账号进入试点前，必须逐项补齐上表字段并再次确认试点时间窗口。
