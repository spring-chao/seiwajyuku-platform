# 学员服务提示验收与数据质量处理清单

日期：2026-08-12  
适用范围：任务 17 的生产只读验收与数据质量收口  
状态：待运营人员执行

## 使用边界

- 本清单只用于查看、核对和记录，不以技术验证为由修改生产数据；
- 学员资料仅从“学员运营 → 学员管理”逐条维护；续费仅从“学员运营 → 续费运营”维护；
- 不启用服务提示反馈，不创建身份、任职、岗位或角色；
- 清单中只记录内部编号或脱敏别名，不记录密码、完整手机号、企业资料或跟进原文。

## 开始前核对

1. 使用具备学员查看权限的运营账号登录统一平台。
2. 打开“学员运营 → 学员管理”，任选真实学员并进入“档案与服务时间线”。
3. 确认“服务提示”标识为“规则只读”，不出现“确认有效”“暂不适用”“数据已修正”等反馈按钮。
4. 本轮已核对的生产门禁为：身份与任职写入、志工服务邀请、服务提示反馈均为关闭状态。若页面显示不同状态，停止本次验收并反馈管理员。

## 完成判定与异常处理

- 四类提示的抽样结果、处理入口和复核责任均已记录，即可提交任务 17 的运营验收结论。
- 如提示与真实业务状态不一致，记录内部编号、提示类型、现状和截图时间；不要直接修改服务提示或开启反馈。
- 如需修改学员资料，在学员管理逐条维护后重新查看该学员时间线，确认提示是否随主数据自然更新。
- 如涉及身份、任职、岗位或数据范围，仅形成候选，不进入生产写入；后续须满足任务 18 的账号、依据、范围、任期和回滚责任人等前置条件。
- 任何签到异常均保持在活动管理的数据复核范围内，不修改 `/event`、`/checkin` 或工作日零点同步链路。
