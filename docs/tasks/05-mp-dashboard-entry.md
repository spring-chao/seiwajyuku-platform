# 任务 5：月 MP/预定/实绩与六中心看板

## 写入门禁

- 导入后的年度方案默认 `DRAFT + write_enabled=false`；
- 只有拥有 `plans:publish` 的用户可提交可追溯批准依据并启用写入；
- 未启用时所有月度更新返回 403；
- 执行期月 MP 基准不可直接修改，预定和实绩可按组织范围更新并审计。

## 看板

- 六个区域分中心按组织 ID 下钻；
- 展示年目标、月 MP、预定、实绩和预定达成率；
- 分母为 0、无数据、不适用和未到期不显示为 0%；
- 苏州塾总目标与六中心聚合差额独立展示；
- 区域角色只能看到授权分中心。

## 前端

`apps/admin-web` 基于 pure-admin-thin 上游改造，新增运营驾驶舱、MP 看板和月度填报页面，复用其布局、路由、权限和 Element Plus 组件。

## 回滚

- 关闭 `annual_plans.write_enabled` 即可立即恢复只读；
- 回退前端与 API 提交不删除导入数据；
- 期间值修改均在审计日志中可追溯。
