# 任务 6：手机号加密、逐人授权和敏感导出隔离

## 默认保护

- 完整手机号使用 Fernet 加密保存；
- 匹配使用 HMAC-SHA256，列表使用后四位和 `138****5678`；
- API 列表、普通导出、审计日志和页面源码不返回完整手机号；
- staging/production 未配置独立字段密钥时拒绝启动。

## 逐人查看

同时满足以下条件才返回一次完整手机号：

1. 用户拥有 `contact:reveal`；
2. 任务对象与学长一致；
3. 当前用户是任务责任人；
4. 任务状态为 OPEN/IN_PROGRESS 且未过期；
5. 任务组织在当前有效数据范围；
6. 填写具体用途。

每次成功访问写入 `contact_access_logs` 和统一审计，日志只保存脱敏号码。

## 导出隔离

- 普通导出强制使用脱敏字段；
- 系统管理员默认没有敏感导出权限；
- 仅数据安全管理员可创建敏感导出；
- 敏感导出需要用途、二次确认、水印、15 分钟有效期和下载审计；
- 密码哈希、令牌和密钥永不进入导出字段。

## 回滚

- 迁移前对非生产源数据备份；
- 新模型与旧库并行，不覆盖旧手机号列；
- 回滚应用后删除新平台导入批次，旧系统继续独立运行；
- 不允许通过回滚把明文手机号重新写入分析表。
