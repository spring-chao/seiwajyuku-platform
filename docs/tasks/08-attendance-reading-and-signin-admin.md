# 任务 8：考勤/读书会自动指标与签到管理迁移

状态：已实现开发基线，待外部系统联调。

## 已实现

- 考勤和读书会快照采用独立 `X-API-Key` 接口接收，按 `source_key + external_id` 幂等去重。
- 接口即使收到手机号，也只保存不可逆哈希与末四位；同步日志不写手机号。
- 支持读书打卡率、班会参与率、小组学习会参与率、工作人员培训参与率、理事会参与率自动计算。
- 只有已获业务批准、处于执行中的年度方案才会写入自动实绩。
- 人工覆盖值始终优先，自动计算只记录 `MANUAL_OVERRIDE_PRESERVED`，不会静默覆盖。
- 管理后台通过本平台 `/api/v1/activities` 查看活动快照和同步状态。

## 迁移边界

- 现场扫码、二维码生成、签到写入继续由现有签到系统独立承担。
- 本平台仅接收快照并提供管理入口，当前实现不替换、不修改现场扫码链路。
- 正式切换前必须完成 API 密钥轮换、字段映射、补数策略、回滚和并行核对。
