# 任务卡 10：组织身份、权限与志工协同体验迭代

- 日期：2026-07-29
- 优先级：P0 业务模型校准 + P1 产品体验
- 状态：代码与文档基础、隔离 MySQL CI、只读灰度已完成；真实账号试点和生产批准待完成

## 目标

在保留现有模块与生产安全边界的前提下：

1. 分开表达运营中心专职人员、学长会员、学长志工和系统技术管理员；
2. 拆分运营中心岗位最小权限；
3. 将志工权限改为有范围、有期限、可撤销的任职授权；
4. 建立运营中心端与志工端双语境；
5. 当前只服务苏州，模型预留未来复制能力。

## 实施顺序

1. 代码级现状审计；
2. 纯新增、兼容读取的数据模型；
3. IAM 授权来源调整；
4. 集中文案适配；
5. SQLite/MySQL 自动测试；
6. 迁移预览、异常清单和受控试点。

## 安全边界

- 不直接修改生产人员归属、角色和权限。
- 不根据姓名、手机号或图表字段推断人员身份。
- 不把运营中心人员归入三级分中心。
- 不把志工任职固化为永久角色。
- 不改变现场扫码签到链路或既有签到事实。
- 不建立志工公开绩效、续费、电话量或服务量排行榜。
- 生产迁移必须在预览、真实账号验收和再次批准后执行。

## 测试与交付

必须覆盖多重身份隔离、雇员岗位权限、志工范围与任期、技术管理员敏感数据隔离、双语境文案、旧 IAM/隐私/签到/续费回归，以及 SQLite/MySQL 前向迁移与回滚。

交付物包括审计报告、迁移设计、兼容映射、权限矩阵、文案字典、代码与测试、迁移预览、异常清单、试点路径、回滚手册和统一记忆更新。
