# 第 12 批任务：志工服务邀请与同行协力

更新时间：2026-07-29

## 目标

在不改变生产人员归属、不默认放开新权限、不触碰现场扫码签到链路的前提下，把现有“直接指派跟进任务”扩展为可选择的服务邀请：

1. 专职人员或服务事项发起人邀请志工担当；
2. 志工可接受、建议调整完成时间或说明本次暂时无法参与；
3. 已接受的担当人可邀请一位有效任职范围内的同行伙伴；
4. 同行伙伴可共同记录服务过程，但不能查看完整联系方式或结束服务事项；
5. 邀请和回应全部留有审计记录。

## 边界

- `VOLUNTEER_SERVICE_INVITATIONS_ENABLED` 默认 `false`。
- 生产环境如未同时获得写入批准，开启该开关会阻止服务启动。
- 旧的 `followup_tasks` 不迁移、不重写，继续按旧流程工作。
- 邀请资格实时复用 IAM 权限和组织范围；任职失效后不能接受邀请。
- “暂时无法参与”不形成参与率、排名或惩罚字段。
- 同行伙伴无完整联系方式访问权，无服务事项关闭权。

## 状态

`PENDING → ACCEPTED`

`PENDING → ADJUSTMENT_REQUESTED → PENDING → ACCEPTED`

`PENDING / ADJUSTMENT_REQUESTED → UNAVAILABLE`

超过 `valid_until` 的待回应邀请按 `EXPIRED` 展示且不能接受。
