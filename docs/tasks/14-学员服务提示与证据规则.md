# 任务 14：学员服务提示与证据规则

状态：第一阶段只读规则已实现并于 2026-08-10 发布到生产环境；第二阶段人工反馈与审计代码已进入任务 16，生产反馈开关仍关闭。第一阶段仍待运营人员结合真实档案做业务口径抽查。

## 目标

在学员“档案与服务时间线”中提供可解释、可核对的服务提示，帮助专职人员发现需要补充资料或进入对应业务页面处理的事项。

本功能不是学长画像评分，不评价积极性、贡献度或流失风险，也不提供个人或组织排名。

## 第一阶段规则

| 规则 | 证据 | 建议动作 |
| --- | --- | --- |
| 联系方式待核对 | 在册档案缺少脱敏手机号 | 由有权限人员补充或确认 |
| 学习班关系待核对 | 在册学员没有生效的 `STUDY_CLASS` 关系 | 普通班选择正式组织；特殊班按既定规则备注 |
| 关怀事项待跟进 | 当前用户有权参与且已经到期的开放事项数量与最早日期 | 进入关怀跟进页处理 |
| 续费节点待处理 | 当前组织范围内、未结束且已到期月份的周期数量 | 进入续费运营页处理 |

## 安全边界

- 只在已有 `members:detail_view` 和组织范围校验通过后返回；
- 关怀与续费提示继续服从对应权限和保密范围；
- 证据仅包含数量、日期和布尔型数据质量事实；
- 不返回手机号、备注、服务原文、企业资料或跟进内容；
- 每条提示包含固定规则版本，不使用不可解释模型；
- 第一阶段不保存提示、不自动创建任务、不修改任何生产数据。
