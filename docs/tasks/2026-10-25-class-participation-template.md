# 班会小组及班级参会统计模板

## 用户确认的呈现

Excel「小组参会统计」和后台签到管理采用同样四列：小组、本组在册人数、本次班会去重到场人数、班会小组参会率；最后增加“班级名称参会率”合计行。后台增加总小组参会率和班级参会率。

## 统计口径与实现

- 本次班会上午、下午按稳定学员身份合并去重，不计空巴、外班、来宾和团队报名名额。
- 小组按当前正式在册成员计算。班级包括全部当前正式在册成员，未分组成员单列“未分组”，防止遗漏分母。
- 总小组参会率按已分组成员人数汇总；班级参会率按全班人数汇总。两者都不平均各组百分比。
- 后台 attendance:view 与 Excel attendance:export 保留各自组织范围，复用同一个服务端统计函数；查看统计不调用敏感的原始导出接口。身份或场次缺失时显示待核对；去重统计临时不可用时不抹去当前场次指标。
- Excel 百分比保留数值，按模板显示整数百分比。签到名单原有小组参会率列保留；签到汇总增加班级与总小组参会率。
- 无数据库迁移、生产数据改写、IAM 或业务门禁变更；本轮不涉及小程序代码。
