# 运营功能现场反馈修复

## 根因与行为

- 签到引擎 `/export` 原合同只输出可读文本，遗漏 `registration_id`、`platform_member_id`、`member_code`、`checked` 等字段。上轮平台测试使用了含标识的合成响应，未覆盖真实导出格式。签到组件 PR #17 补全标识、实际到场快照和签到事实，不修改报名、签到数据。
- 平台同时兼容旧格式：仅在标识均缺失时按唯一有效的姓名+完整手机号在服务端匹配，复用既有导入身份验证；不会按同名或脱敏手机号猜测。各日间场次都执行同样的补全，导出回包继续删除完整手机号。
- 小程序申请页按基本资料、企业、开票、学习期望、补充与进度展示全部表单字段。读者保留脱敏与权限限制；同一申请组织范围内的审核员复用既有完整走访资料能力。完整图片沿用审核权限、接收人/走访用途确认及导出审计，不需要修改 IAM 或生产开关。
- 图片生成与页面使用同一字段目录；长资料按固定画布上限分图，不截断。隐私授权、相册授权、画布及存储故障分别提示，拒绝相册权限时提供设置入口；临时私有图片在离开或保存结束后删除。
- 学习会预览区分本场真实账本已入账分数、本次新增可结算分数、本周期其他场次已计分及受阻项目，并显示逐人逐项目分数与原因。已入账项目使用现有账本分值，不用规则预估分值替代；不重复发放、不修改计分规则或历史账本。
