# 当月活动补签与班会签到最终确认

## 行为

- 有 `attendance:adjudicate` 权限且在组织授权范围内的人员，可在活动全部场次结束后，为当月已匹配、未签到的学长补签。月份按中国时间判断。
- 已签到记录不允许使用补签入口覆盖；补录实际首次到场时间，按已有规则判断迟到、早退和积分，保留操作人、原因及到场时间。
- 后续同步保留补签事实；重复扫码以较早签到时间为准。实时参会统计及 Excel 使用同一补签覆盖层。
- 最终确认针对整场活动全部场次，校验页面核对快照、身份匹配及学分规则完整性，确认后锁定人工裁定。
- 活动日期从 2026-11-01 起，确认时自动结算。较早活动仅确认签到，不自动生成学分账本。重复确认幂等；确认和入账失败整体回滚。
- 保留正式结算开关、环境写入门禁、学分管理员权限及组织范围、既有期初学分边界；未启用时显示待开启，启用后需再次确认入账。无迁移、无权限配置变更、无生产业务数据操作。
- 已入账后源数据变化显示核查提示，不重复入账或静默覆盖账本。
