# 疑似已有档案的确认入塾

- 疑似已有档案的申请在详情显示“确认入塾”，提供当前操作人入塾授权范围内、与申请手机号摘要相同的现有档案供人工核对选择。列表和候选不额外返回完整手机号。
- 必须明确选择同一学长；服务端再次校验手机号匹配及档案组织范围。原审核、收款、申请塾和正式管理单元门槛继续生效。
- 使用已填写的申请资料更新选中的现有档案；保留编号、既有首次入塾日期、班级小组关系及历史记录。空白申请字段不擦除原资料。分中心变更仍执行既有组织规则。
- 更新档案和将申请置为 ENROLLED 使用同一事务；失败整体回滚，重试幂等，不创建第二份档案。敏感财务资料仍加密，审计只记录字段名及操作关联。
- 不执行生产档案合并、不直接更新截图中的业务数据、不改变收款门禁或权限配置。无数据库结构变化。

验证：入塾相关后端 31 项通过，含不匹配档案拒绝、原门槛保留、更新后失败回滚、保留历史身份及重复确认不重复建档；管理端全套 131 项通过，类型检查通过。
