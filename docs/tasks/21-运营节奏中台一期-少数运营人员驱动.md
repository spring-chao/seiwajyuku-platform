# 任务 21：运营节奏中台一期——少数运营人员驱动

## 产品判断

依据《盛和塾运营节奏中台一期_少数运营人员驱动方案_V1.0》，系统承担“记住标准节奏、生成当月事项、提示例外、沉淀结果”的职责；班主任、班委、学习辅导员等继续通过微信、电话和线下协作，不要求所有角色登录系统。

生日关怀助手已作为现有业务能力保留。本期把生日关怀接入月度运营节奏，运营人员可以从节奏事项直接打开生日助手，形成“提醒—核实—关怀草稿—线下执行”的闭环；系统不自动发送、不用 AI 猜测完成、不新增敏感信息展示。

## 一期范围

| 能力 | 实现 |
| --- | --- |
| 节奏模板 | `operation_templates`、`operation_template_nodes`，支持班级月度标准模板和未来模板调整 |
| 月度生成 | 按班级生成 `operation_cycles`、`operation_items`，幂等生成，避免重复事项 |
| 日期规则 | 固定日期、星期序号、相对锚点、跨月截止日、手工确认、生日月份业务节点 |
| 运营视图 | 今日、未来 7 天、本月、需关注四种视图，显示组织、责任角色、外部协作角色和当前状态 |
| 进度沉淀 | `PENDING`、`PLANNED`、`IN_PROGRESS`、`WAITING_EXTERNAL`、`COMPLETED`、`ATTENTION`、`CANCELLED`；状态变更写进度记录和审计 |
| 生日节点 | 每位符合组织范围和有效期的当月生日学员生成独立关怀事项；点击事项进入已上线的生日助手 |

## 权限与安全边界

- 查看要求 `plans:read`，生成、状态更新和模板调整要求 `plans:period_write`；
- 所有事项按 `accessible_org_ids` 限制组织范围，直属苏州班仅接受已确认的四个班级；
- 月度生成和状态更新属于写操作，在生产只读/写入门禁开启时保持关闭；
- 责任角色可以是线下协作角色，不代表已创建账号，也不触发通知或绩效排名；
- 生日事项只复用生日助手的已核实事实和既有审计边界，不展示出生年份，不自动发送。

## 后续边界

本期不自动把签到、完成事实或续费状态回填为“已完成”。后续接入可靠业务事件源后，再按文档中的 P1 范围补充完成事实回填、出席异常、续费和 MP 节点；任何自动化都必须保留来源、时间和人工复核入口。

## 验收

- 同一班级同一月份重复生成不产生重复周期或事项；
- 日期规则能覆盖固定日、相对班会、跨月截止和生日事项；
- 无权限或范围外账号不能读取、生成或更新事项；
- 状态变更可查询进度记录和审计；
- 生日事项能打开现有生日助手，但不会自动发送消息；
- 生产只读门禁下仅保留查看接口，生成、更新和模板写入均被拒绝。
