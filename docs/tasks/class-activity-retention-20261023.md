# 班级会整体参会与合影保留期

用户确认：小组学习会合影由7天延长到1个月。班级会是一场活动，上午、下午、空巴只是扫码场次；整体报名人数为本班人数，上午或下午有效签到去重计入整体参会率，空巴不计。

## 实现

- 合影默认720小时，即30天。上传、读取和清理共用有效到期规则。原标准7天期限且尚未物理删除的对象按上传时间延长至30天，不批量重写数据库元数据。明确撤销、已删除对象不恢复，异常的非标准到期时间不被覆盖。
- 管理端和小程序文案同步为1个月（30天）。生产发布显式设置STUDY_EVIDENCE_RETENTION_HOURS=720，避免历史环境配置覆盖默认值。
- 班级会新增整体报名人数、整体签到人数和整体参会率。2026-10-24 用户明确：分子仅计本班当前在册学员，跨班与嘉宾保留在明细。分子和分母均采用班级与小组管理中的正式当前关系及 ACTIVE 在册状态。仅 MEMBER 类型上午/下午 PRESENT/MANUAL_PRESENT 签到按身份去重；空巴、跨班、嘉宾、非在册不计入。按 member_id、唯一正式学员编号或已核验绑定记录的来源别名识别身份；单独的来源报名 ID 不能证明班级归属，缺少可靠身份的学员记录显示待核实，不按姓名猜测合并。
- 保留原始各场报名、签到、积分及历史事实。管理端列表每活动显示整体人数，详情的整体统计不随场次切换，原分场汇总保留。
- 数据读取沿用活动组织权限，未配置班级时显示待核实。没有签到、积分、账本或组织关系数据写入。

恢复：代码与非敏感保留期配置可回退至发布前版本；延长保留不会删除文件。无需生产数据库迁移，不触碰独立签到部署及计分规则。

2026-10-24 的明确回复覆盖先前所有签到人员的临时默认口径。相关回归覆盖本班去重、跨班与嘉宾排除（含绑定本班身份的嘉宾）、空巴排除、当前正式关系优先于旧成员字段、非在册排除、可靠身份归属与权限隔离。30 天保留规则不变。
