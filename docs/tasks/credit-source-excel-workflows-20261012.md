# 学分来源表格与导出

用户确认：2026年10月以后学分须能追溯来源；班会线下签到、读书打卡、已确认的优秀分享均可上传Excel。表格填写事实，使用原有班级冻结规则计算，不接受任意手填学分。小程序仍只展示正式账本，整数显示截去小数，学习年度每12次实际确认学习日切换。

## 使用

学分结算工作台顶部“表格计学分与导出”：选择班级与记录类型，下载预填学长编号、姓名的模板。身份不匹配、日期、场次、重复记录等按Excel行提示；检查不修改业务数据。保存来源不写账本，随后生成结算预览、提交复核、复核通过、确认入账。日常活动批次沿用既有独立复核规则；期初余额及历史年度仍按已经批准的原规则执行。

- 班会：填写上午、下午、空巴的到场／迟到／早退／请假／缺席，选择已开放的本班周期及实际举办时间。离线记录不伪造扫码时间。既有扫码记录不一致时走签到裁定；已入账事实不由重复上传覆盖。旧月补登保留当前月份，不重复推进。
- 读书：直接接收既有“读书会打卡统计列表”导出表（6列或12列），按姓名与脱敏账户尾号唯一匹配本班学长。录音为按时完成、提前完成或过期完成时，每人每天计1分，周末也计；未提交只留原表，后来完成可重传补录。年度日期日历仍用于日期有效性与来源审计。
  工作台显示2026年已发布日历覆盖天数；缺失时，有既有日历维护权限的管理员可准备系统核准的全年365日日历。使用仓库 `data/learning-calendars/china-mainland-2026.json` 的相同字节资产，走既有日历发布验证与审计；已有发布版本保留，已有同名草稿或历史版本拒绝覆盖。该准备不生成学分。
- 分享：只填写已评定优秀的记录，每次使用稳定的分享编号；沿用优秀分享月度上限。

新增来源最早2026-10-01，最晚当天；不能与已确认期初截止日重叠。上传保留原文件哈希、原行、身份、日期、来源编号、确认人和不可变快照。读书／分享结算仅使用该文件的事实ID，不纳入同班其他文件。账本详情及导出展示文件名与行号；扫码等业务来源保留原业务编号。

导出含三张表：学分汇总（期初及补差、所选期新增、当前累计原值）、新增学分明细（实际日期、来源、规则、冲销）、已导入历史年度（只列已确认年度）。未取得的历史年度不补假数据。导出受导出、名册、学分预览三项权限及组织范围交集限制，保留审计，不包含联系人手机号；文本按字面写入Excel，不能执行公式。

## 数据库与恢复

0072创建来源头、原表行、结算批次关联三张表；不修改旧期初、历史年度、原账本、权限或生产开关。固定管理员准备入口核验发布提交和迁移哈希，保持启动自动迁移关闭。DDL前写入持久开始审计，部分完成时拒绝重放，先检查实际表与标记，再前向补齐；禁止删业务事实来重试。

空结构可执行对应0072回退脚本；有任一来源、行、关联时回退拒绝。0067与0049回退在0072子结构存在时提前拒绝。生产已导入后的代码回退保留新表与来源，采用兼容旧服务或前向修复；不能把代码回退当成学分删除。原活动与账本已形成的事实使用既有裁定／冲销流程。

## 验证

隔离验收覆盖三类来源到正式账本、同一生成者不能自审、重复上传、扫码与离线同日去重、录音未完成及周末、分享月上限、来源篡改、能力范围交集、文件事实过滤、旧月份确认与 typed Excel 导出。新增固定准备、MySQL中断无重放、空回退、保留来源拒绝回退进入现有 study-meeting-mysql CI。生产没有收到本任务的新活动原表，不导入合成学分；只准备空结构并验证真实名册模板及现有学分导出。
