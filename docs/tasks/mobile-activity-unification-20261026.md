# 班会参会统计统一与移动活动管理

日期：2026-10-26

用户要求：解释并修复同一炎武三班班会在活动签到与签到现场的参会率差异，让运营专员在小程序上查看、创建和管理活动。

## 原因与统计规则

活动签到已有规则计入本班当前正式在册学长，以及正式服务本班的班主任、副班主任、小组辅导员；分母为本班当前在册人数。前一轮签到现场／Excel 新增的小组统计只计算了在册学长，遗漏上述师资例外。两端还分别读取保留快照和实时签到数据，存在同步延迟影响。

沿用 `docs/tasks/class-activity-retention-20261023.md` 中用户明确补充的规则，不改变业务门禁：

- 整体参会率：上午、下午有效签到合并去重，本班在册学长加本班正式师资；除以本班当前在册人数。师资本身已在本班在册时不重复增加。
- 小组参会率：当前归组的在册学长到场数／本组在册人数。总小组率按人数汇总，未分组计入班级，不计入总小组分母。
- 空巴、嘉宾、团队名额、其他无正式本班师资任职的跨班参加者不计入整体率。
- 现场、Excel、小程序和活动详情共享实时聚合。活动详情只尝试其精确关联场次，校验班级和日期；不可用时明确标记已同步快照。列表保留有界的本地投影，打开详情后更新对应行整体指标。
- 展示本班学长到场及额外师资人数；导出统计增加额外师资核对行，保持各行到场数可以相加核对。整体率统一保留一位小数；小组率沿用整数百分比模板。

## 手机操作

小程序「移动运营 → 活动管理」支持按月份查看活动、三场班会合并一张活动卡、场次切换、实时班会／小组统计、姓名／单位／小组搜索。

新增班级三场会创建（选择授权班级，核对日期和三场时间；由签到引擎读取可信当前名单并确认场次）、课程等普通活动草稿创建、当前场次名称及签到时间编辑、确认／草稿／取消、签到开关、可信名单增补、当前场次签到码、临时报名、人工签到、请假／预计迟到／恢复待签到、删除未签到报名。小组学习会仍从其专用入口安排。

所有操作复用现有签到引擎，每项权限独立按当前 IAM 组织范围校验；查看权限不能借用为管理权限。已签到事实不可删除或改跟进状态；团队名额不可将联系人直接人工记为到场；已结束／取消及空巴迟到等沿用现有约束。编辑保留未改变的历史时间秒数。跨页面／身份切换丢弃迟到响应和确认回调，签到码临时图片及时删除。创建、报名和人员操作保留持久请求意图，未知写入结果不自动重发。

无数据库结构、生产业务数据、IAM 授权、业务门禁或资源配置变更。
