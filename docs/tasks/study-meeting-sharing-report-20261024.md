# 小组学习会群分享周报

用户每周向学长群分享月度小组学习会完成情况及分中心各班组明细，要求导出自动整理并增加分中心总参会率。

## 交付设计

- 原记录导出增加并默认选择“群分享周报（月度累计）”；原小组汇总、人员学分明细格式保留。
- 一个 Excel 文件先显示分中心／直属班完成总表，再为各分中心／直属班生成明细表，保留没有学习会记录的小组。蓝色表头、隔行底色、姓名自动换行、筛选、冻结表头和横向打印；不导出手机号及内部学分字段。
- 周报单独选择统计月份、截止日期，分中心和班级沿用当前筛选。只计月初到截止日的 SUBMITTED 记录，不受原草稿状态和列表日期筛选混淆；未来或跨月截止日拒绝。默认日期使用北京时间。
- 用户明确确认：按月累计到截止日，每个应开展小组预定一次，总参会率按已完成场次加权。预定采用当前有效小组及对应统计月份的正式周期政策；免开展、暂停开展不计入预定目标，缺失或冲突政策标待配置，不冒充另行下达目标。周期归属复用正式业务月份解析，不用最新OPEN周期覆盖过去月份。
- 总参会率固定按已完成场次的本组参会人数合计／对应当前本组在册人数合计加权，不直接平均各组百分比，不把未完成小组人数加进此分母。免开展小组自愿已提交的真实场次仍列出并纳入实际参会率，但不计完成目标。
- 当前本组人员与在册分母共用班级与小组管理的正式唯一关系；跨组／其他人员单列，保留名单但不进入本组参会率。空分母显示“—”，无学习会的分中心显示零完成而非消失。
- 同组同周期历史重复提交仅选最新已提交记录；不同周期真实场次保留，完成小组数仍去重。小组停用、迁班等归属变化记录单列待核对，不静默放入错误班级。

## 边界与验证

- 沿用普通导出与学分预览权限交集及500场上限；超限拒绝，不截断。源状态、日期或组织在导出期间变化时拒绝。文字型名称不作为Excel公式执行。
- 复用权限校验与当前关系选择器，人员事实批量读取；分享报表无需逐场计算学分，不新增事实、组织、签到或账本写入，仅保留导出审计。
- 隔离测试覆盖加权分母、免开展／暂停／政策缺失、零完成、未完成、同名不同ID、直属班、重复／草稿／取消／截止日、当前关系、权限、字面文本、500场及源变化。样式示例为合成数据，不能当作生产名单验收。
- 代码发布依目标提交的完整CI、MySQL及受控候选验证执行；最终发布和线上下载验收以交付证据为准。
