# 志工班会签到统计与统一场次视图

班主任、副班主任在小程序“志工服务”新增“班会签到统计”。默认当天，可选择月份及本人服务班级，再选择该月份的某次班会。按当前有效正式任职的服务班级组织ID授权，不按学员自己的学习班级或任职名称猜测；志工服务组织指向其他班级时使用其实际服务班级。任职停用、撤销、学员停用、班级停用或主要任职需人工确认时不提供统计访问。

新增服务能力由这两个有效岗位实时推导，不创建后台账号、员工授权或角色目录记录。新接口仅支持读取场次和聚合统计，不返回报名人员姓名、电话、关怀备注、单位、学员编号、照片或管理操作；班级查询范围来自服务端，不接受客户端提供的用户或授权范围。沿用现有签到管理连接开关、可信服务调用与组织校验，未放宽签到引擎边界。

## 四个统计视图

用户确认志工、专员使用同一规则：

- 整体：同一次班会的上午、下午签到按学长身份合并去重，空巴另计。
- 上午：仅上午；下午：仅下午；空巴：仅空巴。各自的班级、小组分子独立去重，不借用整天到场人数。
- 沿用共同参会统计服务：精进组排除分子与分母；未分组计入班级；总小组率为已分组人数的汇总；正式本班师资沿用已确认的额外计入规则，外班、来宾和团队名额排除参会率。现场总人数单独呈现实际签到，保留自愿参加事实。
- 新增每场次小组统计只扩充现有聚合结果，原整体结果、Excel、原始报名签到、学分和任职事实不变。身份待核对或场次不完整时显示待核对/服务错误，不能当作零参会率。

专员小程序活动现场管理新增整体切换；选择具体场次时相应更新统计及管理目标，整体视图提示先选择场次再操作。兼容仅一个场次的旧班会。后台签到现场统计组件也提供四个选择，并与上方现场管理的场次切换联动。
