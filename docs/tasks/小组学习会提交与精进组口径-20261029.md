# 小组学习会提交与精进组口径

用户确认：未提交成功不出现在后台正式记录；提交时明确显示成功或失败；只有名称为“XX班精进组”的小组免学习要求，单独“精进组”正常统计；已有提交记录重新统计，不要求再次提交。合影保留一个月（30天）后清理。

## 处理

- 小程序优先把照片编码为 Base64 JSON，服务端限制传输大小、严格解码，再复用原有图片像素校验、去 EXIF、私有存储、人员授权、草稿状态校验与审计。保留旧 multipart 接口和旧客户端兼容路径。不得在校验响应中回显照片内容。
- 失败原因保留在页面，照片和草稿可重试；只有服务端返回 SUBMITTED 才提示成功并跳转成功页。
- 正式后台、移动运营记录与列表导出隐藏 DRAFT。草稿仍作为断点重试状态保存，避免网络失败后重复登记；原有受权运营纠错和恢复能力继续保留。
- 共用免要求判断只匹配带“班”前缀的完整组名，不拼接旁边显示的班级名称。已提交记录的月度参会率、应开数和导出动态重算。总部读书导入按实际匹配的组织组名判断，裸“精进组”计入正常分母。原始出席、已入账学分与历史导入事实不批量改写。
- 30天保留规则已存在，本次核验生产配置为720小时；未删除的旧7天标准期限照片按原有兼容逻辑延长，已删除照片不恢复。

## 诊断与验收边界

生产访问日志显示有一次草稿创建200，随后两次证据上传400；未包含可确认具体业务拒绝原因的响应正文，不能将其断言为已确认的网关缺陷。合成图片在现有生产私有存储桥的 PUT、GET 完整性和 DELETE 检查通过，测试对象已清理。没有替学员提交真实参会记录或生成真实学分。
