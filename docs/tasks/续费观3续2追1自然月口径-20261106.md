# 续费三阶段自然月口径

用户于2026-11-06明确：追1为当月到期，续2为下月到期，观3为下下月到期，跨年顺延。例如2026年11月：11月追1、12月续2、2027年1月观3。此定义替代原先“距离到期3、2、1个月”的实现。

统一修改服务端日历阶段计算，阶段盘、台账、行动卡及其沟通建议使用相同规则。三个阶段之后为日常维护，已过期的未闭环周期仍归挽回/复盘，已闭环状态优先；不修改任何实际续费结果、到期月份或学员身份。兼容保留旧DUE_NOW代码，但新的日历阶段不再产生额外“到期冲刺”分类，页面不再显示重复当月卡片。

阶段卡打开同一阶段完整台账，避免仅显示“今天需要行动”的子集；服务端授权范围和跨年周期投影沿用既有规则。小程序关注列表原先已按0/1/2月差分组，此次统一服务端阶段名称，增加两者一致性的回归断言。

验证覆盖本月、下月、下下月、跨年、闰年及北京时间月界；相关续费、移动运营和业务时间测试通过。普通代码发布，不需要数据库迁移或人工修正续费事实。发布证据见工作区 `.codex-tmp/reading-sync/renewal-month-stages`。

年度分析的提前、到期月、逾期完成统计按实际月份差判断，避免追1改为当月后被错误算作提前续费。原有历史完成时间、结果证据与比例不改写；关爱汇总的合成测试同步采用新口径。
