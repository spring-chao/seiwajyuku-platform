# 运营查询与移动关爱文案

小组学习会记录初次进入按北京时间当月首日至末日查询，保留自选历史日期。学分来源入账列表初次进入查询最近七个自然日（含今天）的保存记录，提供班级、来源类型、状态、保存时间、查询、重置和分页。分页前在服务端应用授权范围及筛选条件，避免全局最新100条截断其他班级。历史重复来源仍合并显示；分页总数按原始来源记录计。

小程序今日行动的学长详情及续费详情增加重新生成按钮。每次点击通过身份和组织范围校验后调用AI；重复点击受阻，离开页面后的旧响应作废。生成失败、模型不可用或等待期间用户已编辑时保留当前文案。只生成可编辑草稿，不发送微信或修改续费状态。

生日和续费模型允许 `deepseek-v4.1-flash`，继续使用现有腾讯云服务端密钥及匿名上下文。生产先只读核对可用模型；当前cloudbase分组原先仅启用hy3，在保留原有分组模型的前提下追加用户指定模型后，生日及续费匿名调用均返回GENERATED。发布仅修改版本环境变量BIRTHDAY_AI_MODEL，继承其余变量、业务开关及完整版本级VpcConf。无数据库迁移。
