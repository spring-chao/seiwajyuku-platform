# 活动签到管理视图：明细与签到率验证

## 变更范围

- 数据复核待办改为对齐卡片布局，统一显示事项、数量和“查看明细”入口。
- 活动列表增加“签到率”“参会率”和“查看明细”列，低于 50% 的活动以醒目颜色提示。
- 新增活动只读明细窗口：展示活动概览、场次汇总、签到率、参会率和签到记录。
- 增加参会率查询口径：全部活动按活动自动选择；也可只看班级参会率或只看分中心参会率。
- 明细接口只读，不提供签到修改、人工匹配或生产写入口；现有扫码签到链路 `/event`、`/checkin` 未修改。
- 活动与场次通过组织 ID 查询，班级/分中心在册人数与参会人数均从 `member_org_relations` 计算，继续以同步后的活动数据为来源。

## 统计口径

`签到率 = (PRESENT + MANUAL_PRESENT) / 签到记录数`。

`本班参会率 = 班级已签到学员（含人工确认） / 本班在册人数`。

`分中心参会率 = 分中心已签到学员（含人工确认） / 分中心在册人数`。

班级学习会等普通班活动使用本班参会率；报告会等大型活动使用分中心参会率。列表、活动概览和场次汇总同时展示签到率与对应参会率；没有有效分母时显示 `—`，避免把未知误显示为 0%。
