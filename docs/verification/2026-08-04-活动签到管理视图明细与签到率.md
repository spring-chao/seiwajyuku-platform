# 活动签到管理视图：明细与签到率验证

## 变更范围

- 数据复核待办改为对齐卡片布局，统一显示事项、数量和“查看明细”入口。
- 活动列表增加“签到率”和“查看明细”列，低于 50% 的活动以醒目颜色提示。
- 新增活动只读明细窗口：展示活动概览、场次汇总、签到率和签到记录。
- 明细接口只读，不提供签到修改、人工匹配或生产写入口；现有扫码签到链路 `/event`、`/checkin` 未修改。
- 活动与场次通过组织 ID 查询，继续以同步后的活动数据为来源。

## 统计口径

`签到率 = (PRESENT + MANUAL_PRESENT) / 签到记录数`。

列表、活动概览和场次汇总使用同一口径；没有签到记录时显示 `—`，避免把未知误显示为 0%。
