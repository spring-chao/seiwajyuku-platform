# 身份与任职只读灰度前置核验

## 本阶段目标

在不改变生产人员归属、不写入身份任职、不开放新权限的前提下，完成身份与任职试点前的只读门禁核验。

## 核验结果

- 生产 API 健康检查返回 `200`，服务正常。
- `/api/v1/system/environment` 返回 `production=true`、`production_mutations_allowed=false`、`deployment_read_only=true`。
- 身份管理本地隔离测试通过：12 项。
- 生产环境未执行人员、组织、任职或权限写入。
- 现场扫码签到、名单接口和既有签到事实未修改。

## 只读灰度配置

- `IDENTITY_AUTHORIZATION_ENABLED=true`：允许读取已存在的身份授权来源。
- `IDENTITY_ADMIN_WRITES_ENABLED=false`：身份、岗位、志工任职和技术职责写入继续关闭。
- `VOLUNTEER_SERVICE_INVITATIONS_ENABLED=false`：志工服务邀请写入继续关闭。

本次只调整容器默认配置并重新发布，不执行数据库写入；若生产平台仍显示“功能尚未启用”，需刷新并等待 CDN/服务版本切换完成。

生产环境接口复核结果：`identity_authorization_enabled=true`、`identity_admin_writes_enabled=false`、`volunteer_service_invitations_enabled=false`，同时保持 `production_mutations_allowed=false`、`deployment_read_only=true`。

## 页面核验结果

业务负责人已打开生产“身份与任职”页面：

- 页面进入只读灰度状态，明确提示身份管理写入尚未开启；
- `admin` 账号显示为“待确认”，未自动关联自然人；
- 运营中心雇用与岗位、志工任职、技术管理员任期均显示“暂无记录”；
- 未发生任何人员、岗位、任职或权限写入。

## 下一步门槛

下一步只读页面核验需要业务负责人登录生产运营平台，确认试点账号可见范围和敏感字段隔离。身份授权读取开关和身份管理写入开关继续保持关闭；只有确认试点账号、组织范围、任期和回滚责任后，才可另行安排只读灰度。生产身份写入仍需单独明确批准。
