# 身份与任职只读灰度前置核验

## 本阶段目标

在不改变生产人员归属、不写入身份任职、不开放新权限的前提下，完成身份与任职试点前的只读门禁核验。

## 核验结果

- 生产 API 健康检查返回 `200`，服务正常。
- `/api/v1/system/environment` 返回 `production=true`、`production_mutations_allowed=false`、`deployment_read_only=true`。
- 身份管理本地隔离测试通过：12 项。
- 生产环境未执行人员、组织、任职或权限写入。
- 现场扫码签到、名单接口和既有签到事实未修改。

## 下一步门槛

下一步只读页面核验需要业务负责人登录生产运营平台，确认试点账号可见范围和敏感字段隔离。身份授权读取开关和身份管理写入开关继续保持关闭；只有确认试点账号、组织范围、任期和回滚责任后，才可另行安排只读灰度。生产身份写入仍需单独明确批准。
