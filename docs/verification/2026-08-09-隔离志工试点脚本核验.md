# 2026-08-09 隔离志工试点脚本核验

## 本阶段范围

验证本地隔离身份与志工试点种子脚本可以在合成数据上完整建立：

- 苏州运营中心下的隔离分中心、班级和小组；
- 运营中心专职、担当志工、同行志工和技术管理员四类合成账号；
- 学员的正式分中心、班级和小组组织关系；
- 担当邀请与同行协力邀请。

本阶段不连接远程数据库，不读取或写入真实账号、真实学员、生产权限或签到数据。

## 发现并修复的问题

1. 种子脚本曾把班级 ID 当作学员的主分中心，触发“班级不属于所选分中心”。现在主分中心使用 `pilot-center`，班级和小组通过正式组织 ID 传入。
2. 同行志工仅有班级范围时，邀请校验曾强制要求其拥有任务保存的分中心范围。现在邀请和回应会基于学员正式组织关系解析有效范围，班级范围可以安全参与分中心级任务，而不会扩大其数据范围。

## 验证结果

- 隔离种子脚本冒烟测试：通过；
- 志工邀请、跟进任务、IAM 和学员组织关系回归测试：21 项通过；
- 生产门禁未改变：`production_mutations_allowed=false`、`deployment_read_only=true`、`identity_admin_writes_enabled=false`、`volunteer_service_invitations_enabled=false`。

## 下一步门槛

仍需业务负责人逐人确认真实试点账号、自然人关联、岗位或志工任职依据、组织范围、任期和回滚责任人；确认后才可在隔离环境进行真实账号登录验收。生产身份和志工写入继续关闭。
