# 导航信息架构优化验证（2026-08-12）

## 结论

原先将年度规划、学员运营、活动签到与身份任职全部置于“运营驾驶舱”下，职责边界不清。现按业务职责拆分为四个一级菜单，保留全部既有页面地址与页面级角色控制。

| 一级菜单 | 二级页面 |
| --- | --- |
| 运营驾驶舱 | 年度 MP 看板、月度填报 |
| 学员运营 | 学员管理、关怀跟进、续费运营 |
| 活动管理 | 活动与签到 |
| 系统设置 | 身份与任职 |

## 兼容性与验证

- 原有页面地址未改变：`/operations/dashboard`、`/operations/mp-entry`、`/operations/members`、`/operations/followups`、`/operations/renewals`、`/operations/activities`、`/operations/identity-admin`。
- 各页面既有角色限制保持不变；“身份与任职”仍只允许平台与技术管理员访问。
- 单页面分组显式保留父级菜单名称，避免“活动管理”和“系统设置”在侧栏中被自动折叠而失去分类信息。
- `pnpm typecheck` 通过。
- `pnpm build:staging` 通过。
- 本地页面可正常打开至登录页；未使用真实账号登录，因此尚未进行登录后的视觉验收。
