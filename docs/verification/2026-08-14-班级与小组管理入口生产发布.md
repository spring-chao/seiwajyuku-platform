# 班级与小组管理入口生产发布（2026-08-14）

## 问题结论

- 学员编辑页把不在当前分中心组织树中的班级或小组追加为“历史归属，需复核”，但不能把错误挂载的组织节点改回正确父级；
- 吴越三班的稳定组织节点仍直接挂在苏州塾根节点，因此其下属小组也无法按吴江分中心正常选择；
- 原系统没有独立的班级与小组新增入口，不能在“新增学员”中临时创建组织主数据；
- 圆融二班仍为启用节点，但是否停用必须先核验在册学员、下级组织和活动引用。

## 本次优化

- 新增“系统设置 → 班级与小组管理”；
- 支持新增班级、新增小组、调整普通班级所属分中心和安全停用；
- 所有写操作要求 `org:manage` 权限、生产写入门禁、明确确认文字并写入审计日志；
- 调整班级归属仅修改父级 ID，保留班级、小组、学员关系和历史记录的稳定 ID；
- 停用前检查在册学员关系、启用子组织和启用活动，任一存在即失败关闭；
- 学员编辑页增加入口提示，班级或小组不存在时须先维护组织主数据。
