# 续费关爱“今日行动”生产发布核验（2026-08-19）

## 发布结论

“观3续2追1”阶段引擎与单个学长“今日行动卡”已完成后端、管理端和生产发布。阶段由后端基于续费年度、到期月份、当前月份及终态集中判断；行动建议使用可核验的学员主档、续费跟进与学习经历生成，没有接入大模型，也不会自动发送消息、修改续费状态或创建跟进记录。

## 本次发布内容

- 新增 `PREPARE / OBSERVE_3 / RENEW_2 / FOLLOW_1 / DUE_NOW / RECOVERY / CLOSED` 自动阶段；
- 续费周期列表直接返回后端阶段结果，管理端不再要求人工填写阶段；
- 新增只读接口 `GET /api/v1/renewals/cycles/{cycle_id}/action-card`；
- 行动卡提供目标、推荐渠道与原因、微信参考、电话开场、建议问题和“不建议做什么”；
- 从生日关怀抽取共用的 verified memories 服务，只采用可核验的签到、课程、报告会、游学和参访经历；无事实时明确降级，不编造共同记忆；
- 观3阶段禁止主动催缴和直接发送缴费链接；
- 行动卡按当前用户组织范围校验，并记录 `renewals.action_card.view` 审计；
- 管理端续费台账新增“自动阶段”，原“查看/跟进”入口调整为“今日行动”。
