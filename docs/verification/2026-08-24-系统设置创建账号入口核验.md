# 系统设置创建账号入口核验

## 范围

- 系统设置 → 账号管理新增“创建账号”入口。
- 创建流程只生成无角色、无组织范围的初始账号；后续人员、岗位、组织范围和任职期限继续在“身份与任职”完成。
- 后端账号创建接口复用身份写入门禁，未获准时返回 403，避免绕过页面直接写入。

## 验证结果

- 前端 `pnpm typecheck`：通过。
- 账号管理页面 ESLint：通过。
- 后端 IAM 与身份管理定向测试：24 passed。
- 隔离本地数据库浏览器验收：通过。
  - 登录后进入“系统设置 → 账号管理”。
  - “创建账号”按钮和创建表单可见。
  - 二次确认明确无角色、无组织范围。
  - 创建后列表显示“待按身份与任职确认”，临时密码只在成功提示中显示一次。
- 未使用真实账号、手机号或密码；未创建生产账号。

## 发布边界

- 未执行数据库迁移。
- 生产 `IDENTITY_ADMIN_WRITES_ENABLED`、`DEPLOYMENT_READ_ONLY` 和生产变更门禁保持原值；本次只发布代码和前端入口。
- 生产门禁关闭时，页面会显示不可创建的受控提示；需要实际生产创建账号时，另行审批身份写入窗口。
