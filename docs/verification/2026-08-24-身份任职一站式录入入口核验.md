# 身份与任职一站式录入入口核验（2026-08-24）

## 结论

身份与任职管理已补充“人员任职录入”入口，供具备 `iam:manage` 权限的管理员逐人维护。入口支持选择现有无旧角色账号或新建个人账号，并在一次事务中完成自然人关联、运营中心雇佣、多个岗位、多个服务责任组织和审计记录；任一步失败时整单回滚。

本次只完成代码与隔离测试，不打开生产 `IDENTITY_ADMIN_WRITES_ENABLED`，不创建或修改真实账号、自然人、岗位、组织范围与权限。

## 安全边界

- 仍同时受 `iam:manage`、`IDENTITY_ADMIN_WRITES_ENABLED` 和生产写入总门禁约束；页面不能切换环境门禁。
- 一次只录入一人，必须填写岗位、任职起止时间、至少一个服务责任组织、确认依据和业务说明。
- 可为同一雇佣选择多个岗位和多个组织范围，支持 `UNIT` 与 `SUBTREE`，同一组织不得重复添加。
- 新账号不写入旧 `user_roles` 或 `data_scope_grants`；现有账号仍有旧角色时拒绝叠加，须先完成受控迁移或改用新账号。
- 手机号或邮箱形态的登录账号在普通账号列表和审计中脱敏；密码不进入接口响应或审计。
- 新账号页面生成独立临时密码，明确禁止使用多人共享的默认密码。
- 提交前展示人员、岗位、组织范围和有效期摘要；提交后可按单条雇佣或任职停用、结束或撤销，历史与审计保留。
