# P3 小程序四入口收口核验

日期：2026-08-28（Asia/Shanghai）
范围：微信小程序入口与体验收口，不涉及生产发布。

## 结论

`P3 MINI-PROGRAM FOUR-ENTRY READY`

本轮在现有 `apps/wechat-miniprogram` 基础上增加四个用户入口页面，并保留原身份绑定、入塾申请和小组学习会路由。没有新增数据库表、迁移、身份主键或积分结算逻辑。

## 页面与行为

已绑定正式学员首页显示：

- 我的学习：显示已接入的当前学习服务；尚未接入历史学习/学分数据时显示“暂无记录”。
- 扫码：调用微信扫码能力；识别现有学习会或入塾入口格式，其他二维码给出明确提示。
- 我的盛和塾：显示脱敏姓名、班级、小组和已接入志工服务记录。
- 我的服务：仅显示当前身份实际具备的小组学习会登记服务。

未绑定时仍显示“绑定我的学员身份”和“新学长入塾申请”；绑定成功后申请入口从首页隐藏。普通正式学员不会看到学习会登记。
