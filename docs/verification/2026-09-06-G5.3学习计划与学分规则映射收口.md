## 映射模型

`class_learning_bindings` 现在按学习轮次冻结：

| 字段 | 含义 |
| --- | --- |
| `plan_version_id` | 学习计划版本，例如 `standard-3y / 2026` |
| `credit_rule_version_id` | 通用学分政策版本，例如 `STANDARD_3Y_2026 / 2026.1` |
| `course_credit_rule_version_id` | 课程学分政策版本，例如 `STANDARD_3Y_2026 / 2026.1` |

`learning_plan_credit_rule_mappings` 以学习计划 `plan_key + plan_version_label` 为主键范围，显式指向上述两个规则版本。当前 2026 映射只有在映射为 `ACTIVE` 且两个规则版本均为 `PUBLISHED` 时，才可用于首次绑定、重新开始或接续。

正常第 1 年到第 2 年、第 3 年仍使用同一 binding，不重新选择规则版本。既有轮次结算只读取冻结 ID：学习计划或通用规则版本后续变为 `RETIRED` 后，既有轮次仍可预览/结算；新的轮次不能选择退役版本。

课程快照也读取 binding 冻结的课程政策 ID。没有课程映射时只保存事实，课程快照为 `PENDING`、分值为 `NULL`，DRY-RUN 为 `RULE_MAPPING_MISSING`，不从默认目录猜分。

## 边界与 RETIRED 回归

- 未映射 binding：小组会和课程均为 `BLOCKED`，拟得分为 `0`；课程事实保留为 `PENDING`，无课程冻结分值。
- 已绑定学习计划变为 `RETIRED`：既有班会、小组学习会和课程 DRY-RUN 仍为 `READY`。
- 已绑定通用规则变为 `RETIRED`：既有轮次仍可使用冻结规则；尝试用退役计划开启新轮次会被拒绝。
- DRY-RUN 和所有本轮验证均未改变账本。
