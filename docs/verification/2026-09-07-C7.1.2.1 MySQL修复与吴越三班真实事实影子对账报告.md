## 1. MySQL 失败定位与修复

run `34098069856` 的真实错误为：0050 MySQL 文件的注释行含有分号，现有迁移执行器按分号切分时，把注释后半段 `it creates no ledger entries.` 当作 SQL，触发 MySQL 1064。

修复提交：

- `2d75a4f`：移除 0050 注释中的语句分号。
- `8a4a2f0`：修正 MySQL `DATE` 返回原生 `datetime.date` 时被 `_row_eligibility()` 误判为 `INVALID_OCCURRED_DATE` 的兼容问题。
- `0e8c118`：使 C7.1.1 与 C7.1.2 在同一隔离数据库中连续执行时，不因 0050 空回滚/重应用产生错误的迁移顺序假设。
- `e06024d`：识别真实总部文件使用的 `账户` 表头，并加入回归测试，避免脱敏账号在身份匹配前被静默丢弃。
