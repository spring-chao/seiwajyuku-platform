# G5.4-C3 生产执行清单

本清单用于中断恢复。它不是生产授权，也不包含生产连接信息、密码或令牌。

固定业务边界：本阶段不执行历史学分正式 POST，`LEARNING_CREDIT_SETTLEMENT_ENABLED` 必须保持 `false`。

## 恢复原则

- 每一步开始前读取并记录当前状态，不根据上一次口头结论跳步。
- 迁移严格按 `0064 → 0065 → 0066`，不要修改迁移逆序或关闭外键保护。
- 任一 fingerprint、行数、状态或引用计数变化，立即停止并重新审核。
- 生产 staging 事实可以保存，但不得写入正式 `learning_credit_entries`。
- 任何历史正式入账都属于 G5.4-C4，不能由本清单隐含授权。
