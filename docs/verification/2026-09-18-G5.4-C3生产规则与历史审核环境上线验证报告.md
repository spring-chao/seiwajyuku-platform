三条白名单仅允许按未使用占位数据处理：

```text

```

目标分类：

```text

```

不得映射为 canonical rule，不得偷偷改成 alias。`REMOVE_UNUSED_PLACEHOLDER` 只有在以下条件同时满足时才进入计划：

```text
course_key ∈ 三条白名单
rule_version.status = DRAFT
rule.status = PENDING
credit_points = 0
all_reference_count = 0
generic_rule_mapping = 0
course_rule_mapping = 0
study_meeting_course_reference = 0
completion_fact = 0
ledger_reference = 0
```

缺少任何引用证据、版本不是 `DRAFT`、状态不是 `PENDING` 或分值非零，结果均为 `BLOCK`，不会生成删除计划。

删除计划的 before-image 至少包含：

```text
course_key, rule_id, course_name, year_index, credit_points,
status, source, aliases, created_at, updated_at
```

并在审计载荷中保存：

```text

actor
reason = REMOVE_UNUSED_PLACEHOLDER_BEFORE_CANONICAL_FREEZE
timestamp
reconciliation_batch_id
release_commit
```

本轮未执行真实 DELETE；现有代码只生成 fail-closed 审计计划，不连接生产写入适配器。
