## 1. 执行边界

本轮实际执行的生产操作只有：

- 使用 CloudBase 数据库 `--read-only` 查询指定表的结构、数量、状态和时间范围；
- 使用 CloudBase 只读控制面接口读取当前 CloudRun 版本的安全配置名及结算开关值；
- 使用生产环境只读 GET 接口核对运行环境状态；
- 在本地以只读方式解析工作簿。

本轮没有：

- 执行生产迁移或 rollback；
- 写入任何生产表；
- 写入 `learning_credit_entries`、C7 事实表或 HQ 导入表；
- 创建、修改或删除生产学员、组织、学习轮次或规则映射；
- 打开 `LEARNING_CREDIT_SETTLEMENT_ENABLED`；
- 使用当前规则重算 1—8 月历史分；
- 生成 member_id、账本幂等键或历史学分流水。
