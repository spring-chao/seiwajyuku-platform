## 失败关闭

路由未激活时，返回 `CANDIDATE_ROUTE_NOT_ACTIVE`，探针数必须为 0；实例只读等待超时返回 `CANDIDATE_INSTANCE_NOT_READY`。只有明确平台证据证明显式启动必需时才返回 `EXPLICIT_CANDIDATE_START_REQUIRED`，不得调用 `StartVersionInstance`。失败尽力恢复 stable 100% 后停止，不重试第二个 candidate；恢复请求失败或不确定时报告，不盲目重发。

恢复流量与关闭发布单是两个独立门禁：

```text
TRAFFIC_RESTORED = true
RELEASE_ORDER_CLOSED = true/false（只读记录）
```

若发布单仍为 gray/running，只报告 `MANUAL_CLOSE_REQUIRED=true`，不得猜 `cancel/go_back/done`，不得在本授权内执行控制台“取消灰度”。

candidate 连通性可以单独通过，但整个生产阶段仍不能最终 PASS；必须由人工确认目标后再次“放弃灰度”并只读验收关闭状态。
