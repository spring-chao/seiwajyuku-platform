## 3. 代码诊断改动

`TencentCloudSdkApi._tcbr_request()` 现在在 SDK 边界专门捕获 `TencentCloudSDKException`，安全读取：

```text
action
tencent_error_code
request_id_present
request_id
message_redacted
endpoint
request_reached_service
diagnostic_classification
credential_mode
token_present
```

分类规则：

| 条件 | 分类 |
| --- | --- |
| RequestId 为空 | `REQUEST_NOT_PROVEN_REACHED_SERVICE` |
| `ReleaseGray` + `InvalidParameter` | `RELEASE_GRAY_PARAMETER_REJECTED` |
| `ReleaseGray` + `ResourceUnavailable` | `RELEASE_GRAY_RESOURCE_UNAVAILABLE` |
| `ReleaseGray` + `InternalError` | `RELEASE_GRAY_TENCENT_INTERNAL_ERROR` |
| `AuthFailure.*`、`UnauthorizedOperation`、`InvalidCredential`、`SignatureFailure` | `TENCENT_AUTH_OR_PERMISSION_ERROR` |
| `RequestLimitExceeded` | `TENCENT_RATE_LIMITED` |
| 有 RequestId 的其他错误 | `REQUEST_REACHED_TENCENT_SERVICE` |

有 RequestId 时 `request_reached_service=true` 只表示“收到服务端 RequestId 的诊断证据”，不伪装成业务成功；无 RequestId 时只归类为未证明到达，不能直接归因参数错误。

失败清理路径现在合并 SDK evidence 与恢复/关闭 evidence，不再用清理信息覆盖原始异常 metadata。CLI 同时输出常用诊断字段和完整脱敏 `evidence` 对象，仍不会输出请求 payload。

## 5. API Inspector / 官方结构对照

本轮没有 API Inspector 的真实控制台请求抓包，也没有调用 API Explorer 发送请求，因此无法生成“当前控制台实际值”的证明性 diff。只做了离线 SDK 结构与腾讯云当前公开文档的只读对照：

| 字段 | 本地序列化 | 官方文档可见内容 | 结论 |
| --- | --- | --- | --- |
| `GrayType` | `gray` | 输入表示例为 `gray`，示例请求却为 `FLOW` | 语义冲突，`GRAYTYPE_DIFF=UNRESOLVED` |
| `TrafficType` | `URL_PARAMS` | 输入表例为 `HEADERS`，示例请求为空 | 当前 URL 参数语义未由文档示例单独证明 |
| `GrayFlowRatio` | `0` | 示例为 `0` | 结构一致 |
| `VersionFlowItems` | 2 个（253、257） | 示例展示 1 个 | 数量差异需以 Inspector 当前控制台请求为准 |
| `VersionName/FlowRatio` | 253=100、257=0 | `VersionFlowInfo` 示例含这些字段 | 结构一致 |
| `Priority/IsDefaultPriority` | stable=1/true、candidate=2/false | 示例包含这两个字段 | 结构一致 |
| `UrlParam` | 257 使用 `sj_canary`，值已脱敏 | 示例包含 Key/Value | 结构一致，真实值不保存 |

腾讯云当前公开 ReleaseGray 文档说明请求域名为 `tcbr.tencentcloudapi.com`，输出 `RequestId`；文档明确只有请求抵达服务端时才会有 RequestId，并列出 `InvalidParameter`、`ResourceUnavailable`、`InternalError` 等错误。因此本轮将缺失 RequestId 保持为“未证明到达”，而非参数错误。[官方 ReleaseGray 文档](https://cloud.tencent.com/document/product/1243/75872)
