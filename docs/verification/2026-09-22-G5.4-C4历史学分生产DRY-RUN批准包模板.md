# G5.4-C4 历史学分生产DRY-RUN批准包模板

> 本文件是未来生产staging写入的独立批准模板。DRY-RUN不是纯只读：登记批次、匹配和审核会写历史staging表；只有ledger必须保持零写入。

## 固定输入

```text
APPROVAL_ID = <待填>
APPROVAL_WINDOW = <待填>
APPLICATION_COMMIT = <待填完整main SHA>
MAIN_CI_RUN = <待填；要求9/9 PASS>
SOURCE_RULE_VERSION = LEGACY_SUZHOU_2026_V1
SOURCE_WORKBOOK = <待填受控文件名；不得含本地敏感路径>
SOURCE_FILE_SHA256 = <待填>
SOURCE_YEAR = <待填>
AUTHORIZED_ACTOR = <待填>
EXPECTED_SOURCE_ROWS = <待填>
EXPECTED_SOURCE_POINTS = <待填>
```

## 前置条件

```text
GATE-3 0065/0066 = PASS
historical staging schema = PRESENT
ledger = 0 / 0.00
settlement = false
历史正式POST接口/开关 = DISABLED
来源文件双人确认 = PASS
```

必须再次确认`LEGACY_SUZHOU_2026_V1`只保存历史原值和来源身份，不以当前2026规则重算。

## 允许的staging操作

仅允许本批准范围内依次执行：

```text
workbook registration by fixed SHA-256
parser and source total reconciliation
class mapping candidate generation/explicit confirmation
member matching and explicitly authorized review decisions
credit anomaly review
YEAR acceptance / MONTH confirmation
historical DRY-RUN
```

自动匹配、批量确认和人工决定必须分别记录快照指纹、算法版本、actor、reason和幂等键。未在本包列明的歧义不得自动确认。

## DRY-RUN验收

```text
source workbook/sheet/row/column traceability = PASS
original points preserved = PASS
YEAR/MONTH/EXACT_DATE preserved = PASS
class/member/credit/period blockers are fully classified
proposed entry count/points can be recomputed
learning_credit_entries_delta = 0
ledger_write = false
ledger after = 0 / 0.00
settlement = false
```

DRY-RUN结果和所有审批快照冻结后立即停止。不得把`APPROVED`或`READY`状态解释为POST授权。

## 失败关闭

文件哈希、来源总分、行列追踪、匹配快照、时间精度、blocker或ledger不变量任一不符，停止并保留staging证据。不得编辑原文件后沿用旧批次，不得手工改ledger，不得为通过校验删除异常行。

## 明确不授权

向`learning_credit_entries`写入；历史正式POST；开启`LEARNING_CREDIT_SETTLEMENT_ENABLED`；创建统一结算批次生产表；0064/0065/0066；R3；CloudRun发布或路由写入。
