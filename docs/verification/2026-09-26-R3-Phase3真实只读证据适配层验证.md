## 控制面实际接口依据

核对仓库 `scripts/deploy_cloudrun_api.py`、已安装腾讯 SDK 的 request/response 模型及官方文档，使用以下五个固定方法：

- DescribeCloudRunServerDetail
- DescribeVersionDetail
- DescribeReleaseOrder
- DescribeServerManageTask
- DescribeCloudRunPodList

官方依据：[查询发布单](https://cloud.tencent.com/document/api/1243/126756)、[查询版本详情](https://cloud.tencent.cn/document/product/1243/126755)、[官方 Python SDK](https://github.com/TencentCloud/tencentcloud-sdk-python/blob/master/tencentcloud/tcbr/v20220217/tcbr_client.py)。SDK 版本继续由已有 `scripts/requirements-release.txt` 固定，没有新增依赖或升级。

完整 SDK client 留在私有初始化闭包中，只返回五个窄只读方法；adapter 无 `invoke(action)`、`call_api`、通用 raw request 或任何写方法。测试对 SDK 方法引用作精确集合检查。此 Python 接口隔离不是针对恶意同进程反射/猴子补丁的安全沙箱，也不代替账号的 CAM 只读权限；不能据此给采集器写凭据并声称权限已受操作系统隔离。

每次最多一次请求。SDK 显式 `NoopRetryer()`；HTTP 无重试、无重定向、10 秒超时和 64 KiB 响应限制。SDK 异常只保留固定错误类别、安全 error code、RequestId、attempt_count，不输出可能带秘密的 message 或 traceback 链。

## runtime 身份与能力限制

仓库 `app/api/system.py` 确认的只读 GET：

- `/api/v1/system/build-info`
- `/health/live`
- `/api/v1/health`（现有实现仅 `SELECT 1`，不等于业务数据库基线查询）

HTTP transport 只有 `get`，内部 method 固定 GET、路径固定白名单、HTTPS 校验证书、不接收 Cookie/Authorization、无 POST/PUT/PATCH/DELETE。origin 来自同一服务的实时控制面响应；不允许 URI 用户信息、query 或任意路径。

现有 build-info 没有 revision ID，因此不能从相同 commit 推导具体 revision。collector 必须先证明 normal、FLOW、唯一批准 stable=100%、其余=0%、无 URL_PARAMS、发布单终态和对应任务停止，再读取 runtime；其后重读 service/release/revision/task，并逐一比较结构化字段。任何变化整批拒绝为 SNAPSHOT_CHANGED，不混合不同轮次数据，不自动重试。

HTTP 初始观察为 PENDING_BRACKETED_FLOW_PROOF。只有两端路由验证通过，collector 才为 runtime observation 绑定该批 TrafficEvidence 指纹并签封；bundle verifier 拒绝缺失路由证明、错误 revision 或单独 runtime 成功响应。

这是有时间上限的前后观察一致性，不是腾讯云跨接口原子快照，不能证明两次采集之间不存在极短暂 ABA 变化。没有对 0% candidate 做身份推断或重新实现 URL_PARAMS 探针。

## 配置与 UNKNOWN

逐字段比较 image reference/digest、EnvParams 的字段集合和 keyed fingerprints、三个安全开关、VpcId/VpcCIDR/SubnetId/SubnetCIDR，以及 Port、Cpu、Mem、MinNum、MaxNum、PolicyDetails、EntryPoint、Cmd、VolumesConf、Dockerfile、BuildDir、LogPath。

环境变量值、启动命令等不明敏感内容不输出；仅保留带 collector key 的 HMAC 比较值，防止对低熵秘密做普通 SHA 字典猜测。缺失或 null 字段为 UNKNOWN，UNKNOWN 不等于 EQUAL。当前 image 信息来源是 service 的 OnlineVersionInfos；不在该列表的 candidate 或 tag-only 镜像不能凭空得到 digest。

SDK PodList 仅提供 Status，没有独立 Ready condition，因此分别输出 running 与 `readiness=UNKNOWN`，不把 Running 擅自升级为 Ready。总数与本页数量不一致时失败关闭，不把截断页当作完整实例列表。

## 数据库只读路径

QueryId 枚举及不可变 SQL 映射覆盖课程版本/规则、通用版本/规则、映射、绑定、账本、0064/65/66、APPLY audit、placeholder references，以及访问账号/只读属性验证。调用者不能传 SQL、表名或追加语句。固定 SQL 均为 SELECT，没有 FOR UPDATE、GET_LOCK、CALL、DDL、SET 或多语句。

MysqlSelectPort 只接受已建立连接并暴露固定 `read(QueryId)`；不初始化生产连接。适配器要求预配置 read-only session、无活动角色，且可见账号权限全部为 SELECT/USAGE；不以 SET 或权限修改修复不符合条件的连接。不满足或无法证明时拒绝。完整结果两次读取并比较，不一致整批拒绝；后续真实数据库接入仍需受审计的访问授权和连接工厂。本实现不宣称跨多条 SELECT 具备原子事务隔离。

DatabaseBaselineEvidence 输出真实字段而非 `invariants_verified=true`：课程版本 ID/status、rule count、production/canonical fingerprint、通用版本 count/status 和 active rule count、mapping/binding/frozen counts、ledger count/points、三项 migration status、APPLY audit count、placeholder reference count。production/canonical 指纹复用已有 storage-neutral 纯函数；不 import production_operations 或 app.db。

各固定查询记录 Query ID、观察/结束时间、attempt_count、非敏感 target fingerprint 和 result fingerprint。原始业务行不写入 bundle/journal。fixture 数值仅测试用，不代表生产状态。

## 证据可信边界与保密

Service/Revision/Traffic/Release/ManageTask/Runtime/DatabaseBaseline/Pod 为独立 typed Observation。source、subject、时间、原始响应指纹由 adapter 产生，CLI 不能传 closed/verified/route_verified 等布尔结论。对收到的原始响应先脱敏，再 canonical JSON + SHA256；仅结构化最小字段进入证据。

TTL=60 秒，单次/整批采集跨度最多 30 秒，拒绝未来/过期时间和跨窗口拼接。每个云响应必须有合法 RequestId；HTTP 有 correlation ID 时验证并保留。subject 绑定 exact service、revision、release ID、task ID；任务 ReleaseId 必须匹配本次发布单。

Bundle 包含 schema_version、collection_id、service、baseline revision、起止时间、evidence、bundle_fingerprint 和 HMAC seal。逐条证据也签封。离线 verifier 需独立信任的 collector key、期望 service/revision 与当前时间；更改 source/subject/内容/指纹无有效签封即拒绝。fixture realm 无法通过 live realm 校验。

HMAC 证明“由持有可信 key 的采集器产生且未被修改”，不是腾讯云官方响应签名，也不抵御持有签名 key、可修改采集器代码的主机操作者。CLI 不接受任意导入 JSON 重新签封。成功采集才写 bundle 及本地独立 `.verifier-key`；key 不放入 bundle/报告/journal，不得提交或上传，应保存于账号限制目录（Windows 使用目录 ACL，不能仅依赖 POSIX mode）。本次无 live bundle/key 产出。
