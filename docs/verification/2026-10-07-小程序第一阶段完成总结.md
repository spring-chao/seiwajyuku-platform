## 隐私指引口径

实际 API 对应的信息类型保留手机号、选中的照片或视频、剪切板。当前媒体业务仅为合影图片，不上传视频；拍照和微信扫码没有使用独立 camera 组件/摄像头授权接口。定位、通讯录、蓝牙、麦克风等未调用，不额外声明。手填个人、企业、开票资料以及账号与业务记录必须另行说明。

| 信息类型 | 用途 |
| --- | --- |
| 手机号 | 用于用户身份识别、账号绑定、学员信息匹配及提供相关学员服务 |
| 选中的照片或视频 | 用于用户主动上传学习活动及相关业务所需的图片或视频资料；补充当前仅支持图片 |
| 剪切板 | 用于用户主动点击复制收款账号及事务所联系电话，便于办理入塾缴费与联系；仅写入复制内容，不读取用户剪切板中已有的信息 |

详细调用位置、SDK 检查、手填字段及验证边界见[隐私专项核查](2026-10-07-小程序隐私权限专项核查.md)。不应为了消除微信统一类型名称而删除复制功能仍需的声明。
