# 小程序隐私权限专项核查

核查日期：2026-10-07（北京时间）。仓库：`spring-chao/seiwajyuku-platform`；组件：`apps/wechat-miniprogram`；基线：`9e51876fda277662f06e545bd68d41a30642516d`。核查包含当前小程序源文件、此前上传版本 1.0.20261007 的来源 ZIP、当前开发者工具工作副本、该项目官方开发者工具的编译缓存，以及手机号服务端交换实现。未查询真实学员数据、未改变业务授权、未修改微信后台声明。

## 首要结论：剪切板提示的来源

项目源码和原上传来源包均没有 `getClipboardData`、`clipboard.read` 或 `clipboard.readText`。开发者工具该项目的 36 个编译缓存文件也没有读取剪切板 API。已检查本地 require 闭包、WXML 组件和配置，未发现动态 wx API 索引、动态执行代码、npm 包或插件触发的读取行为。

微信官方《小程序用户隐私保护指引内容介绍》明确把 **wx.setClipboardData 与 wx.getClipboardData 同时映射到“读取你的剪切板”**。因此，“代码没有读取调用”和“后台仍需保留这一信息类型”可以同时成立。当前代码中可确定的来源是复制功能；没有独立读取当前后台配置或后台对历史版本的检测结果，不能断言后台没有额外的历史声明。

官方来源：<https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html>（2026-10-07 直接读取）。另见 [setClipboardData 功能定义](https://developers.weixin.qq.com/miniprogram/dev/api/device/clipboard/wx.setClipboardData.html)、[隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)。开发指南说明，未声明对应信息类型会导致隐私接口被禁用；不要为了消除字样而删除复制功能仍需要的声明。

## 手机号、上传与 SDK 数据路径

手机号按钮返回一次性 code，bindIdentity 把它与手填姓名、手机号和 wx.login code 提交给平台。服务端 `apps/platform-api/app/services/wechat_identity.py:305` verify_wechat_phone_ownership 使用微信官方 getuserphonenumber 接口核验手机号归属；没有旧式 encryptedData/iv 客户端解密。wx.login code 在服务端 jscode2session 交换为 OpenID，绑定统一人员身份。工作人员登录另外使用平台账号凭证。不要在公开声明中把“姓名、手机号绑定”误写成“获取微信昵称头像”。

合影是用户点击后选择/拍摄的图片，压缩、检查文件大小，只读取选定临时路径的文件，通过带当前会话凭证的 wx.request 上传至当前学习会 evidence 接口。没有视频选择、录音、后台相册遍历、相册保存或整个文件目录上传。会话变更会中止旧请求。

小程序没有 package.json、npm 依赖、miniprogram_npm、插件 provider、第三方统计/地图/客服/OCR SDK；全部 require 指向本组件相对模块。管理网页的 Vue、Element Plus、ECharts、qrcode、@pureadmin/utils 等不进入小程序包，不能把管理端 UI 依赖误列成小程序隐私 SDK。服务端 CloudBase/腾讯云托管和微信登录/手机号接口是服务与官方接口，并非小程序内嵌统计 SDK；后端实际处理账号、学员业务资料和选定合影，需要纳入整个平台服务说明。

## 微信后台最终填写建议

按当前代码，平台 API 对应的三个信息类型应保留：

| 后台信息类型 | 用途文本 |
| --- | --- |
| 收集你的手机号 | 用于用户身份识别、账号绑定、学员信息匹配及提供相关学员服务 |
| 收集你选中的照片或视频信息 | 用于用户主动上传学习活动及相关业务所需的图片或视频资料 |
| 读取你的剪切板 | 用于用户主动点击复制收款账号及事务所联系电话，便于办理入塾缴费与联系；仅写入复制内容，不读取用户剪切板中已有的信息 |

照片/视频是微信合并的类型名称。按用户要求保留上表用途；补充说明当前仅支持图片，未提供视频上传功能。剪切板也是平台共用类型名称，不能用“用于读取用户复制的内容”替代真实复制用途。
