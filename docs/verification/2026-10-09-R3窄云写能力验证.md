# R3 Phase 4 窄云写能力验证

本轮补齐真实 SDK 写传输的第一部分，不是 R3 生产生命周期控制器。未执行生产请求；无生产 CLI、规则 APPLY、实例停止/删除或自动关闭入口。三个关键环节的目标仍未完成。

## 能力与边界

`scripts/r3_cloud_write.py` 只提供以下方法；完整 SDK client 保留在私有闭包中，不暴露通用 action 分派。

| 方法 | 唯一底层动作 | 固定请求范围 |
| --- | --- | --- |
| create_enable_candidate | UpdateCloudRunServer 一次 | 固定环境/服务；相同不可变 image digest；GRAY；版本级 VpcConf；原环境变量仅 G5 APPLY false→true |
| target_candidate | ReleaseGray 一次 | URL_PARAMS；stable=100、candidate=0；固定定向参数；不切普通流量 |
| restore_stable_flow | ReleaseGray 一次 | FLOW；stable=100、candidate=0；无 URL 参数；不宣称关闭发布单或候选实例 |

创建计划必须提供生产六门禁原值、完整版本级 VPC、子网位于该 VPC CIDR 内及不可变镜像摘要。不接受源码/新镜像构建、FULL、环境变量增删或其他业务开关变化。执行前重新构造固定 typed SDK 请求并逐字段比较，直接构造伪造 plan 也不能扩展动作。

现有 Phase 1/2 状态机和 fixture journal、Phase 3 采集器、普通发布器及业务 API 均未修改。新传输台账不把 fixture 状态转换为生产许可。

## 批准与次数

每个动作需要独立签发的 `R3_CLOUD_WRITE_CAPABILITY`。字段严格为 schema_version、purpose、scope、controller_commit、approval_ref、approved_by、realm、not_before、expires_at、operation_id、action、request_fingerprint、journal_fingerprint、max_attempts。

沿用已有独立 HMAC 授权验证：固定服务范围、干净且获批的完整控制器提交（由后续控制器核验）、明确批准主体/编号、live realm、最多一小时窗口。max_attempts 只能为整数 1。request_fingerprint 使用与批准 key 不同的可信 binding key，对完整计划（含内存中的原环境变量与目标请求）计算 HMAC；避免在公开批准包/台账中保存敏感环境值或对低熵秘密作无 key 摘要。此模块不生成批准、key、ACL，不登录、不读取应用凭据。

WriteAttemptJournal 在 SDK 调用前永久记录 operation/action、批准指纹和 UNKNOWN，使用 SQLite FULL 同步及原子唯一约束。重启、新批准编号和并发调用均不能重放同一 operation/action。换路径不能复用原批准；不能通过新 operation_id 或台账规避未知结果核对。

SDK 固定 tcbr endpoint/region、10 秒超时、NoopRetryer。收到格式正确的 RequestId（创建还要求正整数 TaskId）后，只记录 RESPONSE_RECEIVED。SDK 超时、异常、响应不合法或本地记录失败统一为 OUTCOME_UNKNOWN，不导出原始错误或请求。plan repr、summary、回执及台账不包含环境值、路由 token。

## 当前缺口与继续接线

计划输入与签名不是实时状态证明；本模块尚未完成与可信采集器的接线。因此不能独立用作生产 R3 执行入口。后续 live 控制器必须先核验同窗口真实 cloud/DB/恢复/provenance，绑定原配置和镜像、状态转换/次数，才能调用此传输；创建响应后还需候选身份、配置、VPC、健康及 CLS 证明。定向路由未保存或身份不明时拒绝 APPLY。

规则 APPLY 必须继续走既有认证 HTTP 入口、服务端 system_admin/权限/门禁/事务检查，最多一次，未知结果先核对。恢复流量后必须核验发布单、管理任务、候选实例/路由和最终 false 门禁，不能以 ReleaseGray 成功或零百分比作为关闭完成。真实通道、生产数据授权与 B/C/D 批准尚未固定。

## 实际验证

本地新增传输测试及相关 Phase 1/2/3、CloudRun 网络回归：**220 passed**。新增 42 项覆盖真实 SDK 模型序列化、固定资源/GRAY/零流量、仅单开关差异、独立签名与完整请求绑定、无重试、超时/本地落盘失败、重启/新编号禁重放、8 并发仅一次、摘要保密和到期后不发送。

SDK 使用离线捕获端口，未连接腾讯云。远端 CI 尚待目标提交执行；本地通过不代表生产验证。

接口依据（2026-10-09 核对）：[腾讯云更新服务](https://cloud.tencent.com/document/product/1243/77192)、[操作发布单](https://cloud.tencent.com/document/api/1243/75873)、[数据结构](https://cloud.tencent.com/document/api/1243/75713)。官方说明配置保存可触发全量部署，取消部署不能立刻终止底层任务；因此不新增泛用配置更新或根据取消响应推断候选关闭。
