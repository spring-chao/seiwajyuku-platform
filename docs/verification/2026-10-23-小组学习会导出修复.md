# 小组学习会导出性能与错误提示修复

## 诊断

截图显示没有 HTTP 状态的通用“无法连接 API”提示。该提示不能单独证明用户网络或 API 地址错误；Axios 请求超时、取消以及本地下载处理失败也走相同提示。诊断时线上前后端均为 `24a8dfd1a9e102840f63c3e07a0b3fad2fdeccc1`，API 健康检查正常。

已在隔离数据复现导出路径的性能缺陷：每场重复加载运营详情与学分预览，详情又反复解析权限、组织范围、可编辑目录及结算锁信息；人员工作簿还重复读取整份筛选结果。20 场、每场两人的人员明细，在同一机器的 SQLite 隔离基准中耗时 14.525 秒，调用 `db.connect` 2812 次、`db.execute` 3986 次。线上有数据库往返时会放大耗时，存在超过前端 60 秒限制的明确风险；未取得截图发生时请求追踪，不能将此基准表述为该次生产请求的实测耗时。

## 修改

- 保留普通导出与学分预览权限的交集、组织范围、最多 500 场限制和导出审计。范围检查完成后，在一次导出的只读快照内复用事实及数据库连接，批量读取参会率元数据。
- 导出不再加载无关的编辑控件、审批及修正锁元数据；沿用原学分计算器与逐人观看确认、冻结规则、重复入账判断，不实现另一套计分规则，也不写入学分。
- 人员 Excel 直接使用有类型的行数据，不再二次生成 CSV 和重新筛选；保留姓名、跨组、课程及预计学分列，文本仍按字面值写入。
- 超时、网络失败、取消及 HTTP 错误分别提示。Excel 下载接口的 JSON Blob 错误会安全解码，500 场限制等业务原因可正常展示。空响应或 HTML 页面不再保存为 Excel。
- 导出中显示文件生成状态，防止重复提交；固定当前请求的文件名及格式；失败提示保留在页面供重试查看，成功后提示下载已开始。

## 验证

同样 20 场合成数据，优化后耗时 0.909 秒，`db.connect` 48 次，`db.execute` 402 次。连接调用减少约 98%，本地耗时减少约 94%；这些是隔离测试结果，不保证每次生产请求相同。

相关 API 测试 32 passed、1 skipped（MySQL 并发项由隔离 MySQL CI 验证）；后台类型检查、112 项既有及错误处理测试通过，新增导出交互专项 3 项通过；staging 构建通过。回归覆盖整份筛选、单场、重复场次、空结果、字面文本、数值列、真实计分一致、已入账不重复预计、范围交集、归属变化、500 场限制与取消／失败后可重试。

新增 API 用例位于既有 `test_tabular_exports.py`，已属于现行隔离 MySQL CI 入口。不涉及数据库结构迁移、生产业务数据修正或 IAM 修改。

目标提交 CI、生产发布和最终页面验证另按实际结果记录，源码和本地通过不等于已上线。
