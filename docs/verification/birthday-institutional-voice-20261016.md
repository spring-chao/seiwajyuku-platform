# 生日祝福改为苏州盛和塾口吻

用户明确的三层表达：珍惜学长们因学习相识的缘分、感谢曾经的参与、祝福生活与家庭。发送主体为苏州盛和塾，不把专员与学长描述为熟识关系。

温暖、标准、简洁三种语气均删除逐条年月日、活动全名及入塾年限。已选的可核验经历作为参与依据，按活动类型概括为读书学习、课程学习、相聚共学等；类型不明时只写学习活动，多种类型不展开清单。没有选择经历时不虚构参与。

不写“还记得我们一起”“平时相聚不多”等关系或频率判断。温暖版以生日问候、缘分、参与、生活家庭祝愿自然分段，使用少量表情和纯文本；复制到微信不出现Markdown加粗标记。保留权限、选取事实、审计和人工编辑复制流程，不引入额外模型费用或数据迁移。

验证重点：三种语气的机构主体、无年份/活动清单、无熟悉程度推断；不同活动类型去重与概括、未知类型保守回退；缺失资料或不选经历时不虚构事实。
