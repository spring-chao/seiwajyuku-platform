# 续费与生日微信话术升级

2026-10-15。范围为平台 API 的话术生成，不增加模型调用、费用、外发消息或数据迁移。

## 行为

- 续费保留原有阶段规则，文案区分日常关爱、意向了解、临期确认和过期安排；优先处理需要协助、下次联系尚未到期、暂缓和等待回复，避免连续追问。
- 只在首次日常联系中引用近 180 天内的真实经历，优先取当前候选中最新的一条，不把旧报告会称作“前段时间”，不虚构发送者也到过现场。
- 不把自由文本摘要、内部意愿判断或待办直接拼进对外文案；闭环周期继续不生成续费话术。
- 生日温暖版、标准版和简洁版均使用明确选中的经历；默认选两条，仍支持人工选 0～4 条。新入塾不写“同行0年”，缺少入塾资料不虚构多年陪伴。生日当天按北京时间生成“今天”，其他日期保留月日。
- 未来日期的出席事实暂不作为已经发生的回忆。草稿沿用原有权限、审计、人工编辑和复制入口。

## 示例（虚构称呼）

等待回复：陈学长好，给您留个言，您方便时再回就好。关于接下来是否继续在塾里学习，想听听您的想法。

需要协助：陈学长好，这次想先听听您目前最希望我们协助的事。您方便时说说，我们再一起看看可以怎么安排。

生日温暖版结尾：愿您身体安康，心里有热爱，身边有惦念。也愿工作之外，多些属于自己和家人的轻松时光。
