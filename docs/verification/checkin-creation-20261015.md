# 活动创建组织联动与人工签到说明

## 问题与行为

选择分中心后，旧页面仍展示全部班级；新页面按组织 ID 与父级关系筛选，只展示所选组织下的班级或小组。先选组织再选班级，切换组织会清除不匹配的选择及已读取的名单、版本。原有服务端授权与可信名单要求继续生效。

新建班级学习会时，选择班级后自动生成“班级名称 + 班级学习会”，例如“圆融五班班级学习会”，无需手填。班会名称在创建界面只读，随班级变化；历史活动编辑保留原名。

截图中的浅色人工签到按钮对应团队名额。现有界面禁止将团队报名联系人直接作为实际参加人签到；需通过小程序团队确认入口记录实际参加人。保留该规则，在团队行显示提示，并为禁用按钮增加悬停说明。活动未确认、未开放、已结束、取消或处理中也显示对应原因。点击处理函数增加相同前置检查；不改签到引擎、权限、时间窗口或真实签到记录。
