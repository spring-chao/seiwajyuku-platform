# 班会线下签到结算联动学习周期

## 规则与实现

班会线下签到来源上传、预览及复核不推进周期，也不提前确认班会已举办。来源周期仅关联签到活动，用于冻结预览和学分账本归属。正式结算全部成功且对账一致后，在同一事务中将批次标为 POSTED、确认本期班会并开启下一期；学分仍归属原周期。

失败或部分失败保留当前周期。显式续跑成功或中断对账恢复到 POSTED 后完成联动。已关闭周期是幂等标记；历史补登只确认历史班会，保留当前进度。最后一期结算后完成该学习轮次，不创建超出计划的周期。沿用下一周期排期覆盖和原小组任务收口规则。

自然月不再推进周期。保留旧定时器和读取接口作为无写入兼容入口；旧月更配置即使仍为 true 也不能恢复月更，不应用历史自动修复。人工确认班会仍使用原实际边界规则。生产历史周期与账本不在此次代码发布中批量重写。
