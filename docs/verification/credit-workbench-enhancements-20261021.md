# 学分导出、读书部分导入与学习会筛选

## 业务口径

- 学分汇总及新增明细在班级后增加小组，以导出截止日有效的班级、小组关系展示；没有有效关系的历史余额不猜测小组。
- “当月”为导出截止日所在自然月；当月获得学分按月初至截止日的精确日期正式账本净额计算，排除期初余额与日期不明的历史学分。所选明细起始日不改变月分子。
- 用户已确认满分按已发布计划与规则自动计算。分母使用整月计划：绑定版本的读书日规则及已发布日历、优秀分享月上限、已排期周期的小组出席一次、班会场次满分及去重课程积分。多个班会内容任务不重复计算场次；同课程不重复计入。学习周期不按月份推断，缺少日期、计划、课程或计分配置时显示“待配置”，学分率留空。工作日规则与原始读书报告允许的非工作日事实可能使比率超过100%，不截断真实值。
- 不足完整月份的绑定、多班关系暂显示待配置，表格附满分构成/待配置原因与计划版本，零分母不做除法。
- 读书打卡允许保存有效行；需修正行只保留行号和原因，不持久化被拒绝的原始单元格，不创建其事实或账本。非计分有效原表继续保留以便后续补录。其他导入类型仍要求完整校验通过。
- 原文件哈希及有效行选择被冻结；文件、名册及有效选择变化需重新检查。复核权限、禁止自审、入账开关、幂等及账本复核不变。
- 缺少来源说明时弹出提示并在页面保留错误。仅允许已知本地输入错误原文显示，网络、服务异常仍沿用脱敏错误映射。
- 小组学习会按组织 ID 联动筛选分中心/指导团、班级，服务端与列表/Excel共用过滤，过滤不能扩大权限范围。

## 验证与发布

本地合成数据验证读书部分成功、重复行、公式拒绝、未知学员、有效行入账、重复上传；验证月分子独立于导出明细日期、计划/规则缺失、课程及场次去重、组织权限交集。管理端行为测试、类型检查及本地页面验收；远端 MySQL 与发布结果以最终 CI 和发布回执为准。

用户于本轮后续消息授权“完成后允许生成部署”，替代此前仅开发不部署的限制。无数据库结构变更；不查询或补写真实报名签到，不做生产导入/入账。代码发布不代表相关学长已补签。
