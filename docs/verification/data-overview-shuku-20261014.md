# 数据概览整理与二级塾在册筛选

## 行为

- 数据概览默认展示运营总览，关爱健康、续费分析、运营日程、年度目标分区切换，保留原有操作入口。
- 各分中心当前在册按二级塾单选展示；优先选择授权可见的苏州塾，否则选择可见的首项。切换只影响该在册明细区，上方月度汇总明确显示全部授权组织口径。
- 组织归属按组织 ID 和父链解析，不按名称猜测。同名分中心不会跨塾混合；空二级塾保留选项，归属缺失单列待核。只返回原有授权范围内的分中心及其上级塾名称。
- 当前在册沿用学员主档口径，分中心合计不包含直属学习班和其他管理单位；月份不改变当前在册快照。
- 收紧标题和指标卡；质量提示折叠；关爱组织表保留主要指标，其余明细在行内展开。
- 修正全范围汇总错误标注为苏州塾的问题。未改权限、数据库结构或生产业务数据。

## 验证

- 管理端类型检查通过，67 项测试通过；新增覆盖同名分中心跨塾切换、空塾、授权范围变化和未知归属。
- API 运营快照和班级运营测试 6 项通过；包含仅授权单分中心账号不能看到其他塾分中心、可识别上级塾和空塾保留。
- 管理端 staging 构建通过；最终生产构建另从干净发布提交生成。
- 本地隔离 SQLite + API + 管理端页面核验：五个分区、默认苏州、切换常州显示本塾分中心及独立合计。测试数据均为合成数据。
- 生产发布、目标提交 CI 与线上版本证据保存于工作区 `outputs/data-overview-20261014`，以实际回执为准。
