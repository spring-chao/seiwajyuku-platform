# 学员导出完整字段清单与 Excel 表格样式

## 行为

- 字段清单由服务端统一提供，共 34 项，分基本资料、学习与组织、企业资料、志工任职、受保护字段展示。支持全选可选字段、取消全选、已选计数；一组一行时仍展示个人字段并说明需切换格式。
- 29 个普通字段按现有查看权限提供，包括公司名称、性别、生日、入塾日期、学习时间、塾龄、续费月份、推荐人、职务、企业基本资料及当前志工任职等。字段权限、组织范围取原有普通导出、学员列表及对应资料查看授权的交集。任职功能关闭时不可导出任职。
- 企业资料字段保留企业查看权限及至少 4 字符用途要求，用途写入审计。完整手机号、精确财务、可能含财务的旧企业规模及备注仅列出受保护说明，不通过普通导出读取，不改变原敏感访问流程。
- 完整字段请求长度上限调整为 2048，避免全选后被旧 256 字符限制拒绝。仅查询获授权学员 ID 的选中字段，每批最多 500 人。零值保留数值，日期及字符串使用正确 Excel 类型。
- 小组会汇总、参会率汇总、人员明细及学员表统一添加细线边框、隔行浅底色和 Excel 结构化表格，保留冻结表头、筛选、自动换行及数值百分比。

## 验证

- 相关 API 导出与隐私测试 26 项通过，覆盖完整清单下载、超过旧请求长度的字段选择、越权／范围交集、企业用途、受保护字段拒绝、零值、公式文本及 Excel 边框和结构化表格。
- 管理端 88 项测试、类型检查、staging 构建通过；覆盖全选、格式切换、用途验证、字段加载失败重试及重复下载限制。
- 合成环境页面与下载核验结果、main CI 及实际发布状态以本次发布回执为准。

无数据库迁移、生产业务资料查询或批量更新。普通代码回退可恢复此前行为，管理端发布前保留旧入口。
