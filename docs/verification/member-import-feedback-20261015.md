# 学员管理入口与资料补充回执

## 行为

移除学员管理页中的全量班级预检、直属四班预检、历史岗位承接预览入口，以及专属弹窗和前端处理代码。这些工具针对固定历史批次；保留后台兼容接口、权限校验和审计，不删除历史资料。保留批量调整小组、学员资料补充、新增学员。

资料补充返回并持续显示已提交批次回执：新增/更新人数、组织关系条数、实际补充字段及人数、加密销售收入条数、人工复核数量与原因。字段摘要只包含字段名称和数量，不含字段值、手机号或敏感金额。

成功回执先保存再刷新页面；刷新失败不改变导入成功状态。明确的校验/权限拒绝显示失败；超时、网络和服务器异常显示结果待确认，提示用同文件只读预检核验。重复上传显示此前已成功导入、本次未重复写入，旧批次没有统计明细时明确说明，不默认渲染零更新。

通过已有批次及审计查询回执，无新增表或迁移。仅原操作人可取得其历史回执；当前组织授权范围指纹与导入时不同时隐藏历史统计，避免范围变化后泄露汇总。未给人员新增权限，也未调整写入门禁。

## 验证

- API 资料补充 5 项测试通过：实际字段汇总、不覆盖旧值、敏感值不进入响应、重复文件回执、同文件预检确认、操作人及授权范围隔离、失败事务回滚。
- 管理端类型检查通过；74 项行为测试通过，其中新增重复文件缺失统计、HTTP 结果分类、成功后刷新失败保留回执、写入失败不生成成功回执等测试。
- 界面、生产构建、目标提交 CI 与发布核验结果记录在工作区 `outputs/member-import-feedback-20261015`，以实际回执为准。

不根据截图推断用户此前某次上传是否成功；新界面的同文件预检可确认当前操作人自己的已完成批次。隔离验收使用合成资料，不代为提交生产学员导入。
