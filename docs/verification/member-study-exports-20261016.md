# 学员、小组学习会及个人学分导出

2026-10-16 用户要求新增学员导出字段选择、调整小组会 Excel、显示参会率、按人导出学分，并将学员管理首页默认设为每页 20 条。用户明确选择按“同一学习周期＋同一小组”限制重复登记，完成后统一部署。

## 行为

- 学员列表前后端默认每页 20 条，可切换 20/30/40/50/100。新增“导出学员列表”弹框，选择普通列表字段、一人一行或一组一行，导出全部筛选结果而非当前页。未分组学员单独成行，最多 5000 人。
- 学员 Excel 使用服务端字段白名单，只允许学员编号、姓名、塾、管理单元、班级、小组、脱敏手机号和状态；导出范围取学员查看与普通导出授权的交集。选择小组汇总时不提供无法逐人对应的个人字段。
- 小组会默认下载真正的 `.xlsx`，一组一个学习周期一行，全体姓名同格，另列其中跨组人员；保留人员明细导出及原有预计学分计算和观看确认。
- 小组参会率沿用本组参加人数/当前有效本组在册人数。Excel 的班级参会率按学习周期统计，分中心按自然月份统计；分子为筛选结果内已提交记录涉及的当前有效在册学员去重人数，分母为对应班级当前有效在册人数，分中心仅汇总筛选结果涉及的授权班级，列名与说明明确范围。无分母保留空值，不伪造 0%。
- 历史同组同周期多条记录保留，小组汇总优先采用最新已提交记录并注明重复条数；人员明细仍可追溯每条记录。没有清理或覆盖既有生产事实。
- 同组同周期的非取消记录占用一次登记名额。已提交记录再次上传明确拒绝并提示原编号；完全相同的草稿请求复用原 ID，便于丢失响应或合影上传失败后的重试。不同草稿内容需要通过原记录处理，不静默覆盖。通过事务内小组主记录加锁覆盖并发首次登记；未新增数据库结构。
- 学分导出新增个人选择，汇总、逐笔新增来源及历史年度都应用同一成员条件，并继续受原有组织范围、普通导出权限与学分查看权限约束。不修改计分规则、账本和结算流程。
- Excel 字符串显式保存为文本，避免姓名等内容被识别为公式；数值、日期和百分比分别使用对应格式，支持筛选、冻结表头和自动换行。
