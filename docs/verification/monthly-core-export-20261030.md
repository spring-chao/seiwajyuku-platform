# 分中心月度核心数据与读书导出

## 结果

- 周报中来源明确未完成的“×”标黄。小组使用 `COUNTIF(本组日期区域,"√")/应打卡人天`；正常情况分母为小组在册人数×工作日数，沿用暂停、停学、免要求和有效班级日期排除规则。保存公式缓存以供无需重算的移动端预览。
- 学分页面新增分中心、月份选择和核心数据下载。月份可选历史月份，当前月截止昨天，每月1日可导出完整上月。使用普通导出、学员查看、学分预览权限的组织范围交集，导出记审计，不修改业务记录、日历、名册、学分或数据库结构。
- 六张表按用户提供的《吴江分中心9月核心数据》模板布局生成：学习数据保留左侧小组周/月汇总、右侧逐日打卡及下方轮值分享；学习分析按周/月配对打卡率与分享率；异常人员保留逐日矩阵；活动保留姓名、签到和合并统计；小组会保留指标、月度参会率及明细区；学分保留按人、月份和课程分类的宽表。
- `monthly-core-template.xlsx` 仅保存源文件样式和课程表头；未保存原始姓名、统计结果、日期、公式、批注或超链接。布局按实际月份、班级、小组和人数扩展。
- 未提供普通/轮值分享完整来源、历史月度学分、模板具体课程映射和活动应到名单的单元格留空。月度学分仅计所选月份明确日期的正式账本及冲销净额，不冒充累计学分。活动实到按每场次去重，不跨场次累加。
